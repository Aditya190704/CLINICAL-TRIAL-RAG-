## Overview

The system has a React/Vite client, Firebase Authentication, a Python/FastAPI service, and Google Cloud data/model services. FastAPI verifies Firebase ID tokens before profile, session, matching, or chat operations. The matching workflow retrieves indexed trial chunks from BigQuery, uses Google ADK and Gemini for structured extraction and assessment, verifies evidence in application code, and saves the validated query and full structured result to the owning user's Firestore session.

## High-Level Architecture

```mermaid
flowchart LR
    User[Clinical technician] --> Web[React and Vite]
    Web -->|Sign in| Auth[Firebase Authentication]
    Web -->|Bearer token| API[FastAPI]
    API -->|Verify token| Auth
    API -->|Profile session and chat| DB[(Cloud Firestore)]
    API --> Workflow[Validation and matching workflow]
    Workflow -->|Vector search| BQ[(BigQuery trial chunks)]
    Workflow -->|Structured model tasks| Model[Google ADK and Gemini]
    Ingest[ClinicalTrials.gov ingestion] -->|Chunk and embed| BQ
```

The browser obtains an ID token from Firebase and sends it to FastAPI. The API verifies the token, enforces UID/session ownership, calls the matching or chat workflow, and persists user data through Firebase Admin. Trial ingestion is an offline path independent of user requests.

The evidence dashboard summarizes validated search facts and criterion coverage across the returned shortlist. Criterion detail remains tied to verified trial quotes and supported patient evidence. Its print-ready HTML report is assembled in the browser on demand, includes official ClinicalTrials.gov links, and is not sent back to the API.

## Business Logic

```mermaid
flowchart TD
    Case[Anonymized case] --> Validate{Input checks pass?}
    Validate -->|No| Reject[Return validation error]
    Validate -->|Yes| Urgent{Urgent warning phrase found?}
    Urgent -->|Yes| Notice[Return notice without model or retrieval]
    Urgent -->|No| Extract[Extract structured facts]
    Extract --> VerifyFacts[Verify facts against case]
    VerifyFacts --> Retrieve[Retrieve candidate trial chunks]
    Retrieve --> Refine{No candidates or weak best score?}
    Refine -->|Yes| Optional[Allow one supported refinement]
    Refine -->|No| Cap[Deduplicate and cap candidates]
    Optional --> Cap
    Cap --> Assess[Assess candidates concurrently]
    Assess --> VerifyQuotes[Verify source quotations]
    VerifyQuotes --> Blocker{Verified blocking criterion?}
    Blocker -->|Yes| Excluded[Record verified exclusion]
    Blocker -->|No| Candidate[Rank non-excluded candidates]
    Excluded --> Result[Return evidence and uncertainty]
    Candidate --> Result
```

A request makes one initial retrieval and at most one validated refinement retrieval. Candidate count and assessment concurrency are capped. A verified blocking criterion excludes a trial; otherwise, supported evidence can yield `POSSIBLY_ELIGIBLE`, while no supported criterion evidence yields `COULD_NOT_ASSESS`. The application never treats retrieval similarity as eligibility probability.

Firestore paths are `users/{uid}`, `users/{uid}/sessions/{sessionId}`, and `users/{uid}/sessions/{sessionId}/messages/{messageId}`. Each session stores its title, validated search query, `createdAt`, `searchedAt`, `updatedAt`, matched-trial IDs, complete structured matching result, and status. The result retains criteria assessments and evidence so a reopened session can be restored. Chat turns use deterministic message document IDs, so a retried chat request updates the same records instead of duplicating them. Sidebar listing returns a lightweight result preview; opening a session returns the full result and chat history. BigQuery stores trial chunks and embeddings. The diagram shows conceptual relationships, not a claim that each entity is a separate collection/table.

## Security

- Firebase ID tokens are required for profile, session, matching, and chat routes. Health and readiness routes remain public.
- The backend derives the UID from a verified token, scopes Firestore paths to that UID, and checks session ownership.
- Chat requests can use only trial IDs in the owned session's saved match result.
- The application role is fixed to `clinical_technician` by the backend.
- Firestore client rules deny direct browser access. Admin SDK writes rely on server credentials and API ownership checks.
- Token verification skips a per-request revocation lookup to reduce latency; a revoked token may remain accepted until normal expiration.
- Submitted, identifier-screened patient case narratives, match assessments, and chat turns are persisted under the owning user's session. Delete a session to remove its saved data. The identifier check is limited and does not provide comprehensive de-identification.
- Retrieved trial text and patient input are treated as untrusted. Retrieval is bounded; structured outputs and quotations are validated before final verdicts.
- Identifier screening and urgent phrase checks are limited safeguards, not comprehensive de-identification or emergency triage.
- No regulatory compliance certification is claimed. Results require qualified clinical review.

## Scalability

- Candidate assessment and final-result caps come from configuration; concurrent assessment is bounded by `ADK_CONCURRENCY`.
- Each model call and retrieval call has a timeout. The matching and chat workflows also have derived overall timeouts capped in code.
- BigQuery provides managed vector storage and search. Monitor query cost and latency when tuning `CANDIDATES_TO_RETRIEVE`.
- Ingestion is independent of request handling and can be scheduled externally; the repository does not include a scheduler or autoscaling configuration.
- User data is partitioned by Firebase UID. Session and message retrieval limits bound data returned to the client.
- Production still needs platform-specific autoscaling, rate limits, monitoring, deployment automation, and data-retention policies.

The mocked workflow latency regression test compares the same six delayed assessment calls at concurrency 1 and 6. A local run measured medians of 226.3 ms and 39.9 ms respectively. These values validate the concurrency change in a simulated workflow; they do not predict live model or BigQuery latency.

# Code Guide

This guide explains where the main parts of the Clinical Trial RAG application live. The code is grouped by responsibility so a change to one feature does not need to be mixed into unrelated files.

## Application flow

1. The React app in `frontend/src/App.jsx` connects the workspace, sign-in state, active search session, and screen-level navigation.
2. Reusable UI pieces live under `frontend/src/components/`. Result cards and assessment details are under `components/results/`; session history is under `components/session/`.
3. `frontend/src/api.js` sends requests to FastAPI. `frontend/src/hooks/useSessionManager.js` loads and updates a user's saved sessions.
4. `backend/app/main.py` creates the FastAPI app, applies request middleware, and exposes API routes.
5. `backend/app/agents/workflow.py` coordinates patient parsing, trial retrieval, evidence review, and response creation.
6. Individual backend services live in `backend/app/services/`. Each service handles one responsibility such as chat evidence, authentication, trial storage, or eligibility assessment.

## Comment style

Comments explain why a decision exists or what a block is responsible for. Names and short expressions should explain ordinary code directly; repeating each line in a comment makes changes harder to maintain. Python functions use docstrings for their purpose, while JSX and JavaScript use short comments around non-obvious behavior or grouped sections.

## Safe change checklist

- Keep API request and response shapes in `schemas.py` and update both sides when a shape changes.
- Keep user-owned Firestore reads and writes scoped by the authenticated UID.
- Keep React view components focused on displaying data; move reusable state behavior into hooks and calculations into utilities.
- Keep trial eligibility language cautious and traceable to the evidence shown to the user.

@app.middleware("http")
async def request_logging_middleware(
    request: Request,
    call_next,
):
    """Attach a request ID and log timing without logging request bodies."""

    request_id = (
        request.headers.get("X-Request-ID", "").strip()
        or str(uuid4())
    )

    request.state.request_id = request_id
    context_token = set_request_id(request_id)

    started = time.perf_counter()
    status_code = 500

    try:
        response = await call_next(request)
        status_code = response.status_code

        response.headers["X-Request-ID"] = request_id

        return response

    except Exception as exc:
        log_safe_error(logger, request_id=request_id, step="request", error=exc)
        raise

    finally:
        elapsed_ms = round(
            (time.perf_counter() - started) * 1000,
            2,
        )

        logger.info("request_id=%s step=request_finished status=%s duration_ms=%s", request_id, status_code, elapsed_ms)
        reset_request_id(context_token)

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(
    request: Request,
    exc: RequestValidationError,
):
    """Return a consistent validation response without echoing input values."""

    errors = []

    for error in exc.errors():
        errors.append(
            {
                "field": ".".join(
                    str(part)
                    for part in error.get("loc", [])
                ),
                "message": error.get(
                    "msg",
                    "Invalid input.",
                ),
                "type": error.get(
                    "type",
                    "validation_error",
                ),
            }
        )

    return JSONResponse(
        status_code=422,
        content={
            "detail": "Request validation failed.",
            "errors": errors,
            "request_id": getattr(
                request.state,
                "request_id",
                None,
            ),
        },
    )

@app.post(
    "/api/match",
    response_model=MatchResponse,
    tags=["matching"],
)
async def match(
    req: MatchRequest,
    request: Request,
    user: dict = Depends(require_firebase_user),
):
    """Match an anonymized patient case against processed clinical trials."""

    request_id = getattr(
        request.state,
        "request_id",
        None,
    )
    search_started = False
    search_completed = False

    try:
        # Reject direct identifiers before storing the narrative in Firestore.
        search_query = pipeline.validate_case(req.patient_case)
        session_id = req.session_id
        if session_id:
            session = await run_in_threadpool(user_data.get_session, user["uid"], session_id)
            if session is None:
                raise HTTPException(status_code=403, detail="This matching session is not accessible.")
        else:
            session = await run_in_threadpool(user_data.create_session, user["uid"])
            session_id = session["id"]

        saved_query = await run_in_threadpool(
            user_data.save_search_query,
            user["uid"],
            session_id,
            search_query,
        )
        if not saved_query:
            raise HTTPException(status_code=403, detail="This matching session is not accessible.")
        search_started = True

        result = await pipeline.run_async(search_query, request_id=request_id)
        saved = await run_in_threadpool(
            user_data.save_match_result,
            user["uid"],
            session_id,
            result.model_dump(mode="json"),
        )
        if not saved:
            raise HTTPException(status_code=403, detail="This matching session is not accessible.")
        search_completed = True
        return result.model_copy(update={"session_id": session_id})

    except HTTPException:
        raise

    except ValueError as exc:
        raise HTTPException(
            status_code=400,
            detail=str(exc),
        ) from exc

    except PermissionError as exc:
        log_safe_error(logger, request_id=request_id, step="matching_permission", error=exc)

        raise HTTPException(
            status_code=503,
            detail=(
                "A required service is unavailable "
                "or access is not configured. "
                "Check BigQuery IAM permissions and service credentials."
            ),
        ) from exc

    except WorkflowError as exc:
        raise HTTPException(status_code=exc.status_code, detail=str(exc)) from exc

    except RuntimeError as exc:
        log_safe_error(logger, request_id=request_id, step="matching", error=exc)

        raise HTTPException(
            status_code=500,
            detail="Matching failed. Please try again later.",
        ) from exc

    except Exception as exc:
        log_safe_error(logger, request_id=request_id, step="matching_storage", error=exc)

        raise HTTPException(status_code=503, detail="Matching session storage is unavailable.") from exc

    finally:
        if search_started and not search_completed:
            try:
                await run_in_threadpool(user_data.mark_search_failed, user["uid"], session_id)
            except Exception as exc:
                log_safe_error(logger, request_id=request_id, step="session_failure_status", error=exc)

@app.post(
    "/api/trials/chat",
    response_model=ChatResponse,
    tags=["chat"],
)
async def trial_chat(
    req: ChatRequest,
    request: Request,
    user: dict = Depends(require_firebase_user),
):
    """Answer a question using evidence from the selected trials."""

    request_id = getattr(
        request.state,
        "request_id",
        None,
    )

    try:
        if not req.session_id:
            raise HTTPException(status_code=400, detail="A saved matching session is required for chat.")
        session = await run_in_threadpool(user_data.get_session, user["uid"], req.session_id)
        if session is None:
            raise HTTPException(status_code=403, detail="This matching session is not accessible.")
        owned_trial_ids = set(session.get("matchedTrialIds") or [])
        if not req.trial_ids or any(trial_id not in owned_trial_ids for trial_id in req.trial_ids):
            raise HTTPException(status_code=403, detail="One or more trials are outside this matching session.")
        message_id = req.message_id or uuid4().hex
        existing_turn = await run_in_threadpool(
            user_data.load_chat_turn, user["uid"], req.session_id, message_id
        )
        if existing_turn is not None:
            return ChatResponse.model_validate({
                "answer": existing_turn["answer"],
                "citations": existing_turn["citations"],
                "missing_info": None,
                "session_id": req.session_id,
            })
        result = await chat_answer(
            question=req.question,
            trial_ids=req.trial_ids,
        )
        result["session_id"] = req.session_id
        response = ChatResponse.model_validate(result)
        persisted = await run_in_threadpool(
            user_data.persist_chat_turn,
            user["uid"],
            req.session_id,
            message_id,
            req.question,
            response.answer,
            [citation.model_dump(mode="json") for citation in response.citations],
        )
        if not persisted:
            raise HTTPException(status_code=403, detail="This matching session is not accessible.")
        return response

    except HTTPException:
        raise

    except ValueError as exc:
        raise HTTPException(
            status_code=400,
            detail=str(exc),
        ) from exc

    except PermissionError as exc:
        log_safe_error(logger, request_id=request_id, step="chat_permission", error=exc)
        raise HTTPException(status_code=503, detail="A required evidence service is unavailable or access is not configured.") from exc

    except RuntimeError as exc:
        log_safe_error(logger, request_id=request_id, step="chat", error=exc)
        raise HTTPException(status_code=500, detail="The trial evidence service failed. Please try again later.") from exc

    except Exception as exc:
        log_safe_error(logger, request_id=request_id, step="chat", error=exc)
        raise HTTPException(status_code=500, detail="The chat request failed. Please try again later.") from exc

T = TypeVar("T", bound=BaseModel)

# ADK and model SDK debug output may include prompts, tool payloads, or responses.
logging.getLogger("google.adk").setLevel(logging.CRITICAL)
logging.getLogger("google.genai").setLevel(logging.CRITICAL)

async def run_structured_agent(
    *,
    name: str,
    instruction: str,
    data: dict[str, object],
    output_schema: type[T],
) -> T:
    """Run one stateless task agent; delete its in-memory session on all paths."""
    client = genai.Client(
        enterprise=True,
        project=settings.gcp_project,
        location=settings.gemini_location,
        http_options=types.HttpOptions(
            timeout=max(1, round(settings.adk_timeout_seconds * 1000))
        ),
    )
    app_name = settings.adk_app_name
    user_id = "request"
    session_id = str(uuid.uuid4())
    session_created = False
    service: InMemorySessionService | None = None
    try:
        service = InMemorySessionService()
        model = Gemini(model=settings.gemini_model, client=client)
        agent = LlmAgent(
            name=name,
            model=model,
            instruction=instruction,
            output_schema=output_schema,
            timeout=settings.adk_timeout_seconds,
            include_contents="default",
        )
        await service.create_session(
            app_name=app_name,
            user_id=user_id,
            session_id=session_id,
        )
        session_created = True
        runner = Runner(
            app_name=app_name,
            agent=agent,
            session_service=service,
        )

        # The user payload is JSON data, never instruction text. It cannot
        # alter the system instruction or grant the agent tools.
        message = types.Content(
            role="user",
            parts=[types.Part(text="UNTRUSTED INPUT JSON:\n" + json.dumps(data, ensure_ascii=False))],
        )

        async def collect() -> str:
            final_text = ""
            async for event in runner.run_async(
                user_id=user_id,
                session_id=session_id,
                new_message=message,
            ):
                if event.is_final_response() and event.content:
                    final_text = "".join(
                        part.text or ""
                        for part in event.content.parts or []
                        if part.text is not None
                    )
            if not final_text:
                raise ValueError("Structured agent response was empty.")
            return final_text

        raw = await asyncio.wait_for(
            collect(),
            timeout=settings.adk_timeout_seconds,
        )
        return output_schema.model_validate_json(raw)
    finally:
        try:
            if session_created and service is not None:
                await service.delete_session(
                    app_name=app_name,
                    user_id=user_id,
                    session_id=session_id,
                )
        finally:
            try:
                await client.aio.aclose()
            finally:
                client.close()

class WorkflowError(RuntimeError):
    """Safe, user-facing workflow failure with no provider detail."""

    def __init__(self, code: str, message: str, status_code: int = 500):
        super().__init__(message)
        self.code = code
        self.status_code = status_code


def _log_failure(request_id: str, step: str, exc: BaseException) -> None:
    """Compatibility wrapper for the shared sanitized error logger."""
    log_safe_error(logger, request_id=request_id, step=step, error=exc)


def _text(value: Any) -> str:
    if value is None or isinstance(value, (list, dict)):
        return ""
    return str(value).strip()


def _trial_id(trial: dict[str, Any]) -> str:
    return _text(trial.get("nct_id")).upper()


def _trial_title(trial: dict[str, Any]) -> str:
    return (
        _text(trial.get("brief_title"))
        or _text(trial.get("title"))
        or _text(trial.get("official_title"))
        or _trial_id(trial)
    )


def _trial_url(nct_id: str) -> str:
    return f"https://clinicaltrials.gov/study/{nct_id}"


def _candidate_id(candidate: Any) -> str:
    if isinstance(candidate, dict):
        return _text(candidate.get("nct_id")).upper()
    return _text(getattr(candidate, "nct_id", "")).upper()


def _candidate_value(candidate: Any, key: str, default: Any = None) -> Any:
    if isinstance(candidate, dict):
        return candidate.get(key, default)
    return getattr(candidate, key, default)


def _candidate_score(candidate: Any) -> float:
    try:
        score = float(_candidate_value(candidate, "best_sim", 0.0))
    except (TypeError, ValueError):
        return 0.0
    return score if math.isfinite(score) and 0 <= score <= 1 else 0.0


def _candidate_chunk_ids(candidate: Any) -> list[str]:
    value = _candidate_value(candidate, "chunk_ids", [])
    return [str(item) for item in value if item is not None] if isinstance(value, (list, tuple)) else []


def _string_list(value: Any, limit: int) -> list[str]:
    if isinstance(value, str):
        values = [value]
    elif isinstance(value, (list, tuple)):
        values = value
    else:
        return []
    return [item.strip() for item in values if isinstance(item, str) and item.strip()][:limit]


def _trial_index() -> dict[str, dict[str, Any]]:
    raw = trials()
    if isinstance(raw, dict):
        result = {}
        for key, value in raw.items():
            nct_id = str(key).strip().upper()
            if not re.fullmatch(r"NCT\d{8}", nct_id) or not isinstance(value, dict):
                continue
            record = dict(value)
            record_id = _trial_id(record)
            if record_id and record_id != nct_id:
                continue
            if not record_id:
                record["nct_id"] = nct_id
            result[nct_id] = record
        return result
    result: dict[str, dict[str, Any]] = {}
    for item in raw or []:
        if isinstance(item, dict) and _trial_id(item):
            result[_trial_id(item)] = item
    return result


def _dedupe_candidates(raw: list[Any], index: dict[str, dict[str, Any]]) -> list[Any]:
    by_id: dict[str, Any] = {}
    for candidate in raw:
        nct_id = _candidate_id(candidate)
        if not re.fullmatch(r"NCT\d{8}", nct_id) or nct_id not in index:
            continue
        if bool(_candidate_value(candidate, "untrusted_instruction", False)):
            continue
        trial = index[nct_id]
        if any(contains_instruction_like_text(_text(trial.get(field))) for field in ("title", "brief_title", "official_title", "eligibility_text")):
            continue
        prior = by_id.get(nct_id)
        if prior is None or _candidate_score(candidate) > _candidate_score(prior):
            by_id[nct_id] = candidate
    return sorted(by_id.values(), key=lambda item: (-_candidate_score(item), _candidate_id(item)))


def _merge_candidates(first: list[Any], second: list[Any], index: dict[str, dict[str, Any]]) -> list[Any]:
    return _dedupe_candidates(first + second, index)


def _chunk_index() -> dict[str, Any]:
    raw = chunks()
    if isinstance(raw, dict):
        return raw
    return {
        _text(item.get("chunk_id")): item
        for item in raw or []
        if isinstance(item, dict) and _text(item.get("chunk_id"))
    }


def _get_passages(
    candidate: Any,
    nct_id: str,
    lookup: dict[str, Any] | None = None,
    max_passages: int = 3,
) -> list[dict[str, str]]:
    lookup = lookup if lookup is not None else _chunk_index()
    passages: list[dict[str, str]] = []
    for chunk_id in _candidate_chunk_ids(candidate):
        item = lookup.get(chunk_id)
        if not isinstance(item, dict) or _text(item.get("nct_id")).upper() != nct_id:
            continue
        text = _text(item.get("chunk_text") or item.get("text") or item.get("content"))
        if text:
            passages.append({
                "chunk_type": _text(item.get("chunk_type") or item.get("section")) or "Trial information",
                "text": text[:700],
            })
        if len(passages) >= max_passages:
            break
    return passages


def _verdict_priority(verdict: str) -> int:
    return {
        "ELIGIBLE": 0,
        "POSSIBLY_ELIGIBLE": 1,
        "COULD_NOT_ASSESS": 2,
        "EXCLUDED": 3,
    }.get(verdict, 4)


def _criterion_priority(criteria: list[CriterionResult]) -> tuple[int, int, int]:
    supports = sum(item.impact == "SUPPORTS" for item in criteria)
    unknowns = sum(item.impact == "UNKNOWN" for item in criteria)
    blocks = sum(item.impact == "BLOCKS" for item in criteria)
    # More missing evidence can never improve a candidate's position.
    return (-supports, unknowns, blocks)


def _unresolved_count(criteria: list[CriterionResult]) -> int:
    return sum(item.impact == "UNKNOWN" for item in criteria)


def _refinement_query_is_useful(query: str, initial_query: str) -> bool:
    initial_terms = set(re.findall(r"[a-z0-9]+", initial_query.casefold()))
    refined_terms = set(re.findall(r"[a-z0-9]+", query.casefold()))
    return bool(refined_terms - initial_terms)


def _refinement_query_is_profile_grounded(query: str, profile: PatientProfile) -> bool:
    supported_values = [
        profile.search_query,
        *profile.primary_conditions,
        *profile.comorbidities,
        *profile.current_medications,
        *profile.prior_treatments,
        *profile.key_findings,
    ]
    supported_terms = {
        term
        for value in supported_values
        for term in re.findall(r"[a-z0-9]+", str(value).casefold())
    }
    query_terms = re.findall(r"[a-z0-9]+", query.casefold())
    return bool(query_terms) and all(term in supported_terms for term in query_terms)


def _build_match(
    candidate: Any,
    trial: dict[str, Any],
    assessment: dict[str, Any],
    rank: int,
    chunk_lookup: dict[str, Any],
) -> TrialMatch:
    nct_id = _trial_id(trial)
    return TrialMatch(
        rank=rank,
        nct_id=nct_id,
        title=_trial_title(trial),
        url=_trial_url(nct_id),
        status=_text(trial.get("overall_status") or trial.get("status")) or "Unknown",
        phases=_string_list(trial.get("phases"), 20),
        conditions=_string_list(trial.get("conditions"), 6),
        sponsor=_text(trial.get("lead_sponsor") or trial.get("sponsor")) or None,
        locations=_string_list(trial.get("locations"), 3),
        relevance_score=round(_candidate_score(candidate), 3),
        verdict=assessment["verdict"],
        summary=assessment["summary"],
        criteria=assessment["criteria"],
        dropped_unverified=assessment["dropped_unverified"],
        passages=_get_passages(candidate, nct_id, chunk_lookup),
    )


async def _run_steps(case: str, request_id: str) -> MatchResponse:
    # Make a normal and injection-appended case identical before extraction,
    # conflict checks, retrieval, and evidence verification.
    case = remove_instruction_like_clauses(case)
    try:
        extracted = await extract_patient(case)
        profile = validate_extracted_profile(extracted.profile, case)
    except Exception as exc:
        _log_failure(request_id, "extraction", exc)
        status_code = error_status_code(exc)
        raise WorkflowError(
            "PATIENT_PARSE_FAILED",
            "We could not extract a reliable patient profile. Review the case and try again.",
            status_code=503 if status_code == 429 else 504 if status_code == 408 else 500,
        ) from exc

    conflicts, excluded_values = detect_supported_conflicts(case)
    missing = derive_missing_facts(profile)
    conflicts = list(dict.fromkeys(conflicts))
    assessment_case = remove_conflicting_fact_mentions(case, excluded_values)

    try:
        # Start with validated primary diagnoses. Less common modifiers remain
        # available to a single refinement if the initial retrieval is weak.
        query = " ".join(profile.primary_conditions) or profile.search_query
        query = safe_search_query(query, case, profile)
        for value in excluded_values:
            query = re.sub(rf"(?<!\w){re.escape(value)}(?!\w)", " ", query, flags=re.I)
        query = " ".join(query.split())
        query = safe_search_query(query, case, profile)
        retrieval = ApprovedTrialRetrieval(case=case, profile=profile)
        first_raw = await retrieval.search(query)
        index = _trial_index()
        candidates = _dedupe_candidates(first_raw, index)
    except Exception as exc:
        _log_failure(request_id, "initial_retrieval", exc)
        raise WorkflowError(
            "TRIAL_RETRIEVAL_FAILED",
            "We could not search clinical trials right now. Please try again later.",
            status_code=(
                503 if isinstance(exc, PermissionError) or error_status_code(exc) == 429
                else 504 if isinstance(exc, (asyncio.TimeoutError, TimeoutError))
                else 500
            ),
        ) from exc

    retrieval_calls = retrieval.calls
    if not candidates:
        logger.info("request_id=%s step=matching_complete candidates=0 retrieval_calls=%d", request_id, retrieval_calls)
        return MatchResponse(
            patient_profile=profile,
            matches=[],
            disclaimer=DISCLAIMER,
            missing_key_facts=missing,
            conflicting_facts=conflicts,
            result_message="No suitable trial was found in this search. This does not mean that no suitable trial exists.",
        )

    try:
        # Criteria checks are independent model calls. Bound their concurrency
        # to avoid serial latency while respecting the configured provider cap.
        assessment_limit = max(1, int(settings.adk_concurrency))
        semaphore = asyncio.Semaphore(assessment_limit)
        assessment_cap = max(0, min(HARD_MAX_ASSESSMENTS, int(settings.candidates_to_judge)))

        async def assess_candidate(candidate: Any) -> tuple[str, dict[str, Any]]:
            nct_id = _candidate_id(candidate)
            trial = index[nct_id]
            async with semaphore:
                output = await assess_trial(case=assessment_case, profile=profile, trial=trial)
            criteria, _, dropped = verify_judge_output(assessment_case, profile, index[nct_id], output)
            verdict = compute_verdict(criteria)
            summary = (
                "A potentially disqualifying criterion was identified in this preliminary review. A qualified clinical team must verify it."
                if verdict == "EXCLUDED"
                else "The available evidence was insufficient to assess this trial's criteria. A qualified clinical team must review the official criteria."
                if verdict == "COULD_NOT_ASSESS"
                else "The available criteria do not establish eligibility. Some information may be missing or unassessed; a qualified clinical team must review the official criteria."
            )
            return nct_id, {
                "criteria": criteria,
                "summary": summary,
                "dropped_unverified": dropped,
                "verdict": verdict,
            }

        async def assess_candidates(items: list[Any]) -> dict[str, dict[str, Any]]:
            assessment_tasks = [asyncio.create_task(assess_candidate(item)) for item in items]
            try:
                return dict(await asyncio.gather(*assessment_tasks))
            except BaseException:
                for task in assessment_tasks:
                    if not task.done():
                        task.cancel()
                await asyncio.gather(*assessment_tasks, return_exceptions=True)
                raise

        # Weak retrieval refinement used to sit on the critical path before
        # any eligibility work began. Overlap its optional model/search work
        # with assessment of the initial shortlist. Strong results never pay
        # for refinement, and the backend still permits at most two searches.
        initial_candidates = candidates[:assessment_cap]
        should_refine = (
            not candidates
            or _candidate_score(candidates[0]) < REFINEMENT_MIN_SIMILARITY
        )
        refinement_task = None
        if should_refine:
            refinement_task = asyncio.create_task(
                propose_refinement(case=case, profile=profile, candidate_count=len(candidates))
            )

        try:
            assessments = await assess_candidates(initial_candidates)
        except BaseException:
            if refinement_task is not None and not refinement_task.done():
                refinement_task.cancel()
                await asyncio.gather(refinement_task, return_exceptions=True)
            raise

        if refinement_task is not None:
            refined_candidates = None
            try:
                proposal = await refinement_task
                if proposal.refine:
                    refined_query = safe_search_query(proposal.search_query, case, profile)
                    for value in excluded_values:
                        refined_query = re.sub(
                            rf"(?<!\w){re.escape(value)}(?!\w)",
                            " ",
                            refined_query,
                            flags=re.I,
                        )
                    refined_query = " ".join(refined_query.split())
                    if (
                        refined_query
                        and _refinement_query_is_profile_grounded(refined_query, profile)
                        and _refinement_query_is_useful(refined_query, query)
                    ):
                        second_raw = await retrieval.search(refined_query)
                        candidates = _merge_candidates(candidates, second_raw, index)
                        retrieval_calls = retrieval.calls
                        refined_candidates = candidates[:assessment_cap]
            except BaseException as exc:
                if not isinstance(exc, Exception):
                    if refinement_task and not refinement_task.done():
                        refinement_task.cancel()
                    raise
                # Refinement is optional. Preserve valid initial results if the
                # optional agent or second retrieval fails.
                _log_failure(request_id, "optional_refinement", exc)
            if refined_candidates is not None:
                missing_candidates = [
                    item for item in refined_candidates
                    if _candidate_id(item) not in assessments
                ]
                if missing_candidates:
                    assessments.update(await assess_candidates(missing_candidates))
                candidates = refined_candidates
        candidates = candidates[:assessment_cap]
    except Exception as exc:
        _log_failure(request_id, "criteria_assessment", exc)
        status_code = error_status_code(exc)
        raise WorkflowError(
            "JUDGEMENT_PIPELINE_FAILED",
            "We could not complete trial criteria assessment. Please try again later.",
            status_code=503 if status_code == 429 else 504 if status_code == 408 else 500,
        ) from exc

    ranked = sorted(
        candidates,
        key=lambda candidate: (
            _verdict_priority(assessments[_candidate_id(candidate)]["verdict"]),
            _unresolved_count(assessments[_candidate_id(candidate)]["criteria"]),
            -_candidate_score(candidate),
            _candidate_id(candidate),
        ),
    )
    ruled_out = []
    for candidate in ranked:
        nct_id = _candidate_id(candidate)
        assessment = assessments[nct_id]
        if assessment["verdict"] != "EXCLUDED":
            continue
        blocker = next(
            (item for item in assessment["criteria"] if item.impact == "BLOCKS"),
            None,
        )
        if blocker is not None:
            reason = f"Verified blocking criterion: {blocker.criterion_quote}"[:500]
            ruled_out.append(
                RuledOutTrial(
                    nct_id=nct_id,
                    title=_trial_title(index[nct_id]),
                    reason=reason,
                )
            )
    shortlist = [
        candidate
        for candidate in ranked
        if assessments[_candidate_id(candidate)]["verdict"] != "EXCLUDED"
    ][:min(MAX_SHORTLIST_RESULTS, max(0, int(settings.final_results)))]
    chunk_lookup = _chunk_index()
    matches = [
        _build_match(
            candidate,
            index[_candidate_id(candidate)],
            assessments[_candidate_id(candidate)],
            rank,
            chunk_lookup,
        )
        for rank, candidate in enumerate(shortlist, start=1)
    ]
    logger.info(
        "request_id=%s step=matching_complete candidates=%d results=%d retrieval_calls=%d",
        request_id,
        len(candidates),
        len(matches),
        retrieval_calls,
    )
    return MatchResponse(
        patient_profile=profile,
        matches=matches,
        disclaimer=DISCLAIMER,
        missing_key_facts=missing,
        conflicting_facts=conflicts,
        ruled_out_trials=ruled_out,
        result_message=(
            "No suitable trial was found in this search. This does not mean that no suitable trial exists."
            if not matches
            else None
        ),
    )


async def run_workflow_async(case: str, request_id: str | None = None) -> MatchResponse:
    """Async workflow entry point, independent of FastAPI request objects."""
    request_id = request_id or str(uuid.uuid4())
    started = time.perf_counter()
    try:
        return await asyncio.wait_for(_run_steps(case, request_id), timeout=MAX_WORKFLOW_SECONDS)
    except asyncio.TimeoutError as exc:
        _log_failure(request_id, "workflow_timeout", exc)
        raise WorkflowError(
            "WORKFLOW_TIMEOUT",
            "Trial matching took too long to complete. Please try again.",
            status_code=504,
        ) from exc
    finally:
        logger.info("request_id=%s step=workflow_finished duration_ms=%d", request_id, int((time.perf_counter() - started) * 1000))


def run_adk_workflow(case: str, request_id: str | None = None) -> MatchResponse:
    """Sync adapter for CLI and sync callers; refuses nested event loops."""
    try:
        asyncio.get_running_loop()
    except RuntimeError:
        return asyncio.run(run_workflow_async(case, request_id=request_id))
    raise RuntimeError("An event loop is already running; await run_workflow_async instead.")

"""Deterministic validation helpers for ADK-extracted patient facts."""

from __future__ import annotations

import re

from app.schemas import PatientProfile
from app.services.untrusted_text import contains_instruction_like_text, remove_instruction_like_clauses

MAX_SEARCH_QUERY_LENGTH = 2000


def _normalized_text(value: str) -> str:
    return re.sub(r"[^a-z0-9]+", " ", value.casefold()).strip()


def _fact_is_supported(fact: str, case_normalized: str) -> bool:
    normalized_fact = _normalized_text(fact)
    return bool(normalized_fact) and normalized_fact in case_normalized


def _validate_profile(profile: PatientProfile, patient_case: str) -> PatientProfile:
    """Discard extracted facts and query terms not supported by the case."""
    case_normalized = _normalized_text(patient_case)

    age_matches = list(re.finditer(
        r"\b(?:(?:age|aged)\s*)?(\d{1,3})(?:\s*years?\s*old|-year-old|\s*yo)?\b",
        patient_case,
        re.I,
    ))
    explicit_ages = [
        match for match in age_matches
        if re.search(r"(?:years?\s*old|-year-old|\byo\b)", match.group(0), re.I)
        or re.match(r"(?:age|aged)\s*\d", match.group(0), re.I)
    ]
    age_values = list(dict.fromkeys(int(match.group(1)) for match in explicit_ages))
    # Keep the extracted age only when the model's value agrees with the case.
    # A validator should discard unsupported model output, not invent a new fact.
    if (
        len(age_values) != 1
        or profile.age_years is None
        or int(profile.age_years) != age_values[0]
    ):
        profile.age_years = None

    stated_sexes = {
        value.upper()
        for value in re.findall(r"\b(?:male|female)\b", patient_case, re.I)
    }
    if profile.sex not in stated_sexes or len(stated_sexes) != 1:
        profile.sex = "UNKNOWN"

    for field_name in (
        "primary_conditions",
        "comorbidities",
        "current_medications",
        "prior_treatments",
        "key_findings",
    ):
        setattr(
            profile,
            field_name,
            [
                fact for fact in getattr(profile, field_name)
                if _fact_is_supported(fact, case_normalized)
                and not contains_instruction_like_text(fact)
            ],
        )

    # Build a stable query from validated diagnoses and clinically relevant
    # findings/treatments. Raw case prose can include irrelevant details.
    query_facts = list(dict.fromkeys([
        *profile.primary_conditions,
        *profile.key_findings,
        *profile.prior_treatments,
        *profile.current_medications,
    ]))
    profile.search_query = (
        " ".join(query_facts)
        or remove_instruction_like_clauses(patient_case)
    )[:MAX_SEARCH_QUERY_LENGTH]
    return profile

@dataclass
class Candidate:
    """Trial candidate with fused relevance and evidence chunk IDs."""

    nct_id: str
    rrf: float = 0.0
    best_sim: float = 0.0
    chunk_ids: list[str] = field(default_factory=list)
    untrusted_instruction: bool = False


def validate_embeddings(
    vectors: list[list[float]],
    expected_dim: int | None = None,
) -> list[list[float]]:
    """Validate vector dimensions, non-emptiness, and numerical values."""
    if not vectors:
        raise ValueError("Cannot perform vector search with empty vectors list.")

    dim = expected_dim or int(settings.embedding_dim)
    validated: list[list[float]] = []

    for idx, vec in enumerate(vectors):
        if not isinstance(vec, (list, tuple)):
            raise ValueError(f"Vector at index {idx} must be a list/sequence of numbers.")
        if len(vec) != dim:
            raise ValueError(
                f"Embedding dimension mismatch at index {idx}: expected {dim}, "
                f"got {len(vec)}."
            )
        for dim_idx, val in enumerate(vec):
            if val is None or math.isnan(val) or math.isinf(val):
                raise ValueError(
                    f"Vector at index {idx} contains invalid numerical value {val} at dimension {dim_idx}."
                )
        validated.append([float(x) for x in vec])

    return validated


def build_vector_search_sql(
    project_id: str | None = None,
    dataset_id: str | None = None,
    table_id: str | None = None,
    num_queries: int | None = None,
    query_count: int | None = None,
    top_k: int | None = None,
) -> str:
    """Construct a parameterized BigQuery VECTOR_SEARCH GoogleSQL query."""
    count = num_queries if num_queries is not None else query_count
    if count is None or count <= 0:
        raise ValueError("num_queries must be greater than 0")

    proj = project_id or settings.gcp_project
    ds = dataset_id or settings.bigquery_dataset
    tbl = table_id or settings.bigquery_chunks_table

    subquery_parts = [
        f"SELECT {i} AS query_id, @q{i} AS query_vector"
        for i in range(count)
    ]
    query_subquery = "\n      UNION ALL\n      ".join(subquery_parts)
    full_table_path = f"`{proj}.{ds}.{tbl}`"

    sql = f"""
SELECT
  query.query_id AS query_id,
  base.chunk_id AS chunk_id,
  base.nct_id AS nct_id,
  base.chunk_text AS chunk_text,
  base.chunk_type AS chunk_type,
  base.metadata_json AS metadata_json,
  distance
FROM VECTOR_SEARCH(
  TABLE {full_table_path},
  'embedding',
  (
    {query_subquery}
  ),
  query_column_to_search => 'query_vector',
  top_k => @top_k,
  distance_type => 'COSINE'
)
ORDER BY query.query_id, distance ASC, base.chunk_id ASC
"""
    return sql.strip()


def execute_vector_search(
    client: bigquery.Client,
    vectors: list[list[float]],
    top_k: int,
) -> list[bigquery.Row]:
    """Execute VECTOR_SEARCH against the configured BigQuery table."""
    project = settings.gcp_project
    dataset = settings.bigquery_dataset
    table = settings.bigquery_chunks_table

    sql = build_vector_search_sql(
        project_id=project,
        dataset_id=dataset,
        table_id=table,
        num_queries=len(vectors),
    )

    query_params: list[bigquery.ArrayQueryParameter | bigquery.ScalarQueryParameter] = [
        bigquery.ArrayQueryParameter(f"q{i}", "FLOAT64", [float(x) for x in vectors[i]])
        for i in range(len(vectors))
    ]
    query_params.append(bigquery.ScalarQueryParameter("top_k", "INT64", top_k))

    job_config = bigquery.QueryJobConfig(
        query_parameters=query_params,
        default_dataset=f"{project}.{dataset}",
    )

    query_job = None

    def cancel_query_job() -> None:
        if query_job is not None:
            try:
                query_job.cancel()
            except Exception:
                pass

    try:
        query_job = client.query(sql, job_config=job_config, location=settings.bq_location)
        rows = list(query_job.result(timeout=settings.adk_timeout_seconds))
        return rows
    except gcp_exceptions.NotFound as exc:
        cancel_query_job()
        log_safe_error(logger, request_id=None, step="vector_search", error=exc)
        raise RuntimeError("BigQuery trial search is unavailable.") from exc
    except gcp_exceptions.Forbidden as exc:
        cancel_query_job()
        log_safe_error(logger, request_id=None, step="vector_search", error=exc)
        raise PermissionError("BigQuery access is not configured.") from exc
    except gcp_exceptions.BadRequest as exc:
        cancel_query_job()
        log_safe_error(logger, request_id=None, step="vector_search", error=exc)
        raise RuntimeError("BigQuery trial search could not be completed.") from exc
    except gcp_exceptions.GoogleAPICallError as exc:
        cancel_query_job()
        log_safe_error(logger, request_id=None, step="vector_search", error=exc)
        raise RuntimeError("BigQuery trial search could not be completed.") from exc
    except Exception as exc:
        cancel_query_job()
        log_safe_error(logger, request_id=None, step="vector_search", error=exc)
        raise RuntimeError("BigQuery trial search could not be completed.") from exc


def _row_val(row: Any, key: str, default: Any = None) -> Any:
    if isinstance(row, dict):
        return row.get(key, default)
    if hasattr(row, "get"):
        try:
            return row.get(key, default)
        except Exception:
            pass
    return getattr(row, key, default)


def fuse_and_deduplicate(rows: list[Any]) -> list[Candidate]:
    """Process BigQuery vector search rows with Reciprocal Rank Fusion and NCT deduplication.

    For cosine distance, similarity is defined as max(0.0, 1.0 - distance).
    RRF score is calculated as 1.0 / (60 + rank) for the highest-ranking chunk
    of each trial per query.
    """
    if not rows:
        return []

    # Group rows by query_id
    grouped_by_query: dict[int, list[Any]] = defaultdict(list)
    for row in rows:
        q_id = int(_row_val(row, "query_id", 0) or 0)
        grouped_by_query[q_id].append(row)

    candidates: dict[str, Candidate] = defaultdict(lambda: Candidate(nct_id=""))

    for q_id, q_rows in grouped_by_query.items():
        seen_trials_in_query: set[str] = set()

        for rank, row in enumerate(q_rows):
            cid = _row_val(row, "chunk_id")
            nct = _row_val(row, "nct_id")
            distance = _row_val(row, "distance", 1.0)

            if not nct or not cid:
                continue

            nct = str(nct).strip().upper()
            cid = str(cid).strip()

            try:
                distance_float = float(distance)
            except (TypeError, ValueError):
                distance_float = 1.0

            similarity = max(0.0, min(1.0, 1.0 - distance_float))

            cand = candidates[nct]
            cand.nct_id = nct
            if contains_instruction_like_text(str(_row_val(row, "chunk_text", "") or "")):
                cand.untrusted_instruction = True

            if cid not in cand.chunk_ids:
                cand.chunk_ids.append(cid)

            if nct not in seen_trials_in_query:
                cand.rrf += 1.0 / (60 + rank)
                seen_trials_in_query.add(nct)

            cand.best_sim = max(cand.best_sim, similarity)

    return sorted(candidates.values(), key=lambda c: (-c.rrf, -c.best_sim, c.nct_id))


def retrieve(
    queries: list[str],
    top_k: int | None = None,
) -> list[Candidate]:
    """Retrieve trial candidates matching the given patient queries using BigQuery VECTOR_SEARCH.

    Parameters:
        queries: List of query strings (e.g. [patient search query, case text]).
        top_k: Optional number of chunks to retrieve per query (defaults to settings.top_k_chunks).

    Returns:
        List of Candidate objects sorted by RRF relevance descending.
    """
    if isinstance(queries, str):
        queries = [queries]

    valid_queries = [
        q.strip()
        for q in queries
        if isinstance(q, str) and q.strip()
    ]
    if not valid_queries:
        logger.warning("Empty or whitespace-only queries provided to retrieve(); returning empty list.")
        return []

    # Generate embeddings using the existing embedding service
    vectors = embed(valid_queries, task_type="RETRIEVAL_QUERY")

    # Validate vector format and dimension
    validate_embeddings(vectors, expected_dim=settings.embedding_dim)

    # Get BigQuery client
    client = get_bigquery_client()

    # Execute search
    effective_top_k = int(top_k or settings.top_k_chunks)
    rows = execute_vector_search(client, vectors, top_k=effective_top_k)

    # Fuse, deduplicate, and sort candidates
    return fuse_and_deduplicate(rows)

        except Exception:
            return False
    try:
        return int(status) in TRANSIENT_STATUS_CODES
    except (TypeError, ValueError):
        return False


def _validate_task_type(task_type: str) -> TaskType:
    allowed = {"RETRIEVAL_DOCUMENT", "RETRIEVAL_QUERY"}

    if task_type not in allowed:
        raise ValueError(
            "task_type must be RETRIEVAL_DOCUMENT or RETRIEVAL_QUERY."
        )

    return task_type  # type: ignore[return-value]


def _normalize_vector(
    values: Sequence[float],
    expected_dim: int,
) -> list[float]:
    """Validate an embedding vector and normalize it to unit length."""
    if len(values) != expected_dim:
        raise RuntimeError(
            f"Embedding dimension mismatch: received {len(values)}, "
            f"expected {expected_dim}. Check EMBEDDING_DIM and the index schema."
        )

    vector = [float(value) for value in values]

    if not all(math.isfinite(value) for value in vector):
        raise RuntimeError(
            "Embedding response contains non-finite values."
        )

    norm = math.sqrt(sum(value * value for value in vector))

    if norm == 0:
        raise RuntimeError(
            "Embedding service returned a zero-magnitude vector."
        )

    return [value / norm for value in vector]


def _embed_batch(
    client: genai.Client,
    texts: list[str],
    task_type: TaskType,
) -> list[list[float]]:
    """Embed a batch with exponential backoff for transient failures."""
    expected_dim = int(settings.embedding_dim)
    last_error: Exception | None = None

    for attempt in range(MAX_RETRIES):
        try:
            response = client.models.embed_content(
                model=settings.embedding_model,
                contents=texts,
                config=types.EmbedContentConfig(
                    task_type=task_type,
                    output_dimensionality=expected_dim,
                ),
            )

            embeddings = getattr(response, "embeddings", None)

            if not embeddings or len(embeddings) != len(texts):
                raise RuntimeError(
                    "Embedding service returned an unexpected number "
                    "of vectors."
                )

            vectors: list[list[float]] = []

            for item in embeddings:
                values = getattr(item, "values", None)

                if values is None:
                    raise RuntimeError(
                        "Embedding response is missing vector values."
                    )

                vectors.append(
                    _normalize_vector(values, expected_dim)
                )

            return vectors

        except Exception as exc:
            last_error = exc

            if attempt == MAX_RETRIES - 1 or not _is_transient_error(exc):
                break

            # Short bounded backoff avoids a long request storm when quota is exhausted.
            delay = RETRY_DELAY_SECONDS * (2**attempt)

            log_safe_error(logger, request_id=None, step=f"embedding_retry_{attempt + 1}", error=exc)

            time.sleep(delay)

    log_safe_error(logger, request_id=None, step="embedding_batch", error=last_error or RuntimeError())

    raise RuntimeError(
        "Could not generate embeddings. Check Vertex AI quota, "
        "project, model availability, and region settings."
    ) from last_error


def embed(
    texts: Sequence[str],
    task_type: str = "RETRIEVAL_DOCUMENT",
) -> list[list[float]]:
    """Generate normalized embeddings in batches, preserving input order.

    RETRIEVAL_DOCUMENT is for indexing trial text.
    RETRIEVAL_QUERY is for embedding patient search queries.
    """
    validated_task_type = _validate_task_type(task_type)

    if isinstance(texts, str):
        raise ValueError(
            "texts must be a sequence of strings, not one string. "
            "Pass [text] to embed a single item."
        )

    clean_texts: list[str] = []

    for index, text in enumerate(texts):
        if not isinstance(text, str):
            raise ValueError(
                f"Input at position {index} must be a string."
            )

        cleaned = text.strip()

        if not cleaned:
            raise ValueError(
                f"Input at position {index} is empty."
            )

        clean_texts.append(cleaned)

    if not clean_texts:
        return []

    client = genai.Client(
        vertexai=True,
        project=settings.gcp_project,
        location=settings.gcp_location,
        http_options=types.HttpOptions(
            timeout=max(1, round(settings.adk_timeout_seconds * 1000))
        ),
    )

    all_vectors: list[list[float]] = []
    last_request_time: float | None = None

    try:
        total = len(clean_texts)

        for start in range(0, total, BATCH_SIZE):
            batch = clean_texts[start : start + BATCH_SIZE]

            # Pace requests to reduce quota bursts.
            if last_request_time is not None:
                elapsed = time.monotonic() - last_request_time
                wait_time = REQUEST_INTERVAL_SECONDS - elapsed

                if wait_time > 0:
                    time.sleep(wait_time)

            logger.info(
                "Embedding batch %d/%d (%d texts).",
                start // BATCH_SIZE + 1,
                math.ceil(total / BATCH_SIZE),
                len(batch),
            )

            vectors = _embed_batch(
                client=client,
                texts=batch,
                task_type=validated_task_type,
            )

            last_request_time = time.monotonic()
            all_vectors.extend(vectors)

            logger.info(
                "Embedded %d/%d chunks.",
                len(all_vectors),
                total,
            )

        if len(all_vectors) != total:
            raise RuntimeError(
                "The number of generated vectors does not match "
                "the input count."
            )

        return all_vectors

    finally:
        client.close()

def _norm(value: str) -> str:
    """Normalize text for case-insensitive substring verification."""
    return re.sub(r"[^a-z0-9]+", " ", (value or "").lower()).strip()


def _quote_in(text_norm: str, quote: str) -> bool:
    """Check quote text; support ellipses only when each meaningful part exists."""
    parts = [
        part.strip()
        for part in re.split(r"\.\.\.|â€¦", quote or "")
        if len(_norm(part)) >= 12
    ]
    return bool(parts) and all(_norm(part) in text_norm for part in parts)

# ---------------------------------------------------------------------------

def _age_check(profile: PatientProfile, trial: dict) -> list[CriterionResult]:
    """Apply deterministic checks from structured trial metadata."""
    results: list[CriterionResult] = []
    age = profile.age_years

    if age is not None:
        lo = trial.get("min_age_years")
        hi = trial.get("max_age_years")

        if lo is not None and age < lo:
            results.append(
                CriterionResult(
                    source="STRUCTURED",
                    criterion_type="INCLUSION",
                    criterion_quote="Minimum age: " + str(trial.get("min_age", lo)),
                    patient_evidence=f"Age: {age:g}",
                    impact="BLOCKS",
                    explanation="The patient's age is below the trial's minimum age requirement.",
                )
            )
        elif hi is not None and age > hi:
            results.append(
                CriterionResult(
                    source="STRUCTURED",
                    criterion_type="INCLUSION",
                    criterion_quote="Maximum age: " + str(trial.get("max_age", hi)),
                    patient_evidence=f"Age: {age:g}",
                    impact="BLOCKS",
                    explanation="The patient's age is above the trial's maximum age requirement.",
                )
            )
        elif lo is not None or hi is not None:
            age_range = (
                f"Age range: {trial.get('min_age') or 'N/A'} "
                f"to {trial.get('max_age') or 'N/A'}"
            )
            results.append(
                CriterionResult(
                    source="STRUCTURED",
                    criterion_type="INCLUSION",
                    criterion_quote=age_range,
                    patient_evidence=f"Age: {age:g}",
                    impact="SUPPORTS",
                    explanation="The patient's age is within the structured trial age range.",
                )
            )

    sex = trial.get("sex", "ALL")
    if sex != "ALL" and profile.sex != "UNKNOWN":
        matches = sex == profile.sex
        results.append(
            CriterionResult(
                source="STRUCTURED",
                criterion_type="INCLUSION",
                criterion_quote=f"Sex: {sex}",
                patient_evidence=f"Sex: {profile.sex}",
                impact="SUPPORTS" if matches else "BLOCKS",
                explanation=(
                    "The patient's sex matches the trial requirement."
                    if matches
                    else "The patient's sex does not match the trial requirement."
                ),
            )
        )

    return results


def verify_judge_output(
    case: str,
    profile: PatientProfile,
    trial: dict[str, Any],
    output: JudgeOutput,
) -> tuple[list[CriterionResult], str, int]:
    """Verify model quotes and convert unknown or unsupported evidence safely."""
    eligibility_text = str(trial.get("eligibility_text") or "")
    eligibility_norm = _norm(eligibility_text)
    case_norm = _norm(case)
    verified: list[CriterionResult] = []
    dropped = 0

    for item in output.criteria:
        quote = item.criterion_quote.strip()
        patient_evidence = item.patient_evidence_quote.strip()
        if not quote or _norm(quote) not in eligibility_norm:
            dropped += 1
            continue

        impact = item.impact
        if impact == "UNKNOWN":
            patient_evidence = ""
        elif not patient_evidence or _norm(patient_evidence) not in case_norm:
            impact = "UNKNOWN"
            patient_evidence = ""

        verified.append(CriterionResult(
            source="TRIAL_TEXT",
            criterion_type=item.criterion_type,
            criterion_quote=quote,
            patient_evidence=patient_evidence or None,
            impact=impact,
            explanation=item.explanation.strip()[:1000],
        ))

    results = _age_check(profile, trial) + verified
    if not verified:
        results.append(CriterionResult(
            source="STRUCTURED",
            criterion_type="INCLUSION",
            criterion_quote="Eligibility assessment could not be completed",
            patient_evidence=None,
            impact="UNKNOWN",
            explanation="No trial criterion could be verified for assessment. Manual review is required.",
        ))

    return (
        results,
        output.summary.strip()[:2000] or "Insufficient evidence was provided to assess the trial criteria.",
        dropped,
    )


# ---------------------------------------------------------------------------
# Deterministic Final Verdict
# ---------------------------------------------------------------------------

def compute_verdict(criteria: list[CriterionResult]) -> str:
    """
    The LLM NEVER determines the final eligibility label.

    Rules:
    - Any BLOCKS criterion -> EXCLUDED
    - No supported criterion evidence and no blocker -> COULD_NOT_ASSESS
    - Otherwise -> POSSIBLY_ELIGIBLE

    Assessments are selective and may omit unreported or unassessed criteria,
    so passing the assessed criteria alone cannot establish trial eligibility.
    """
    if any(c.impact == "BLOCKS" for c in criteria):
        return "EXCLUDED"

    if not any(c.impact == "SUPPORTS" for c in criteria):
        return "COULD_NOT_ASSESS"

    return "POSSIBLY_ELIGIBLE"

def _processed_dir() -> Path:
    """Return the configured local directory for processed JSON files."""
    return Path(settings.processed_dir)


def _gcs_object_candidates(filename: str) -> list[str]:
    """Return supported GCS paths, preferring the configured prefix."""
    prefix = str(settings.gcs_prefix or "").strip("/")
    candidates: list[str] = []

    if prefix:
        candidates.extend(
            [
                f"{prefix}/{filename}",
                f"{prefix}/processed/{filename}",
            ]
        )

    candidates.append(filename)

    # Preserve order and remove duplicate paths.
    return list(dict.fromkeys(candidates))


def _read_gcs_json(filename: str) -> Any | None:
    """Read JSON from GCS. Return None when no matching object exists."""
    bucket_name = str(settings.gcs_bucket or "").strip()

    if not bucket_name:
        return None

    client = storage.Client(project=settings.gcp_project)

    try:
        bucket = client.bucket(bucket_name)

        for object_name in _gcs_object_candidates(filename):
            blob = bucket.blob(object_name)

            try:
                if not blob.exists():
                    continue

                content = blob.download_as_text(encoding="utf-8")
                return json.loads(content)

            except json.JSONDecodeError as exc:
                logger.error(
                    "Invalid JSON in GCS object %s (%s).",
                    object_name,
                    type(exc).__name__,
                )
                raise RuntimeError(
                    f"The stored file {filename} contains invalid JSON."
                ) from exc

        return None

    finally:
        client.close()


def _read_local_json(filename: str) -> Any | None:
    """Read JSON from the configured local processed directory."""
    file_path = _processed_dir() / filename

    if not file_path.is_file():
        return None

    try:
        with file_path.open("r", encoding="utf-8") as file:
            return json.load(file)

    except json.JSONDecodeError as exc:
        logger.error(
            "Invalid JSON in local processed file %s (%s).",
            filename,
            type(exc).__name__,
        )
        raise RuntimeError(
            f"The local processed file {filename} contains invalid JSON."
        ) from exc


def _load_json(filename: str) -> Any:
    """Prefer GCS, then fall back to local processed files."""
    if settings.gcs_bucket:
        try:
            data = _read_gcs_json(filename)

            if data is not None:
                logger.info("Loaded %s from GCS.", filename)
                return data

            logger.warning(
                "GCS object for %s was not found; "
                "trying the local processed directory.",
                filename,
            )

        except RuntimeError:
            raise

        except Exception as exc:
            logger.warning(
                "GCS read failed for %s (%s); trying local storage.",
                filename,
                type(exc).__name__,
            )

    data = _read_local_json(filename)

    if data is not None:
        logger.info("Loaded %s from local processed storage.", filename)
        return data

    raise FileNotFoundError(
        f"Could not find {filename} in the configured GCS locations "
        f"or local directory {_processed_dir()}."
    )


def _extract_records(
    data: Any,
    filename: str,
) -> list[dict[str, Any]]:
    """Normalize list-based and dictionary-based JSON into records."""

    # Format 1: a JSON array of records.
    if isinstance(data, list):
        records = data

    elif isinstance(data, dict):
        # Format 2: records wrapped in a named list.
        records = None

        expected_fields = (
            ("trials", "items", "records", "data")
            if filename == TRIALS_FILENAME
            else ("chunks", "items", "records", "data")
        )

        for field in expected_fields:
            value = data.get(field)

            if isinstance(value, list):
                records = value
                break

        # Format 3: chunks.json is a dictionary keyed by chunk ID.
        #
        # Example:
        # {
        #   "NCT07601178::overview::0": {
        #       "nct_id": "NCT07601178",
        #       "type": "overview",
        #       "text": "..."
        #   }
        # }
        if records is None and filename == CHUNKS_FILENAME:
            if data and all(
                isinstance(value, dict)
                and {
                    "nct_id",
                    "type",
                    "text",
                }.issubset(value.keys())
                for value in data.values()
            ):
                records = []

                for chunk_id, value in data.items():
                    record = dict(value)

                    # Keep the existing ID if one is already present.
                    record.setdefault("chunk_id", chunk_id)

                    # Preserve the dictionary key as a fallback ID.
                    records.append(record)

    else:
        records = None

    if not isinstance(records, list):
        root_keys = (
            list(data.keys())[:10]
            if isinstance(data, dict)
            else []
        )

        raise RuntimeError(
            f"{filename} has an unsupported JSON structure. "
            f"Expected a list or supported dictionary format. "
            f"Root keys: {root_keys}"
        )

    if not all(isinstance(record, dict) for record in records):
        raise RuntimeError(
            f"{filename} contains one or more records "
            "that are not JSON objects."
        )

    return records


def _load_records(filename: str) -> list[dict[str, Any]]:

    records = _extract_records(data, filename)

    for record in records:
        nct_id = str(record.get("nct_id") or "").strip().upper()

        if nct_id:
            record["nct_id"] = nct_id

    return records

def _lexical_score(question: str, text: str) -> float:
    """Small local-store fallback score; not a clinical eligibility score."""
    question_tokens = Counter(_tokenize(question))
    passage_tokens = Counter(_tokenize(text))

    if not question_tokens or not passage_tokens:
        return 0.0

    overlap = sum(
        min(count, passage_tokens.get(token, 0))
        for token, count in question_tokens.items()
    )

    # Normalize the overlap so long passages do not automatically win.
    denominator = math.sqrt(
        sum(question_tokens.values()) * sum(passage_tokens.values())
    )
    return overlap / denominator if denominator else 0.0


def _cosine_similarity(query_vector: list[float], document_vector: Any) -> float:
    """Compute cosine similarity for a query and a stored embedding."""
    if not isinstance(document_vector, (list, tuple)):
        return 0.0

    try:
        document = [float(value) for value in document_vector]
        query = [float(value) for value in query_vector]
    except (TypeError, ValueError):
        return 0.0

    if not query or len(query) != len(document):
        return 0.0

    if not all(math.isfinite(value) for value in query + document):
        return 0.0

    dot_product = sum(a * b for a, b in zip(query, document))
    query_norm = math.sqrt(sum(value * value for value in query))
    document_norm = math.sqrt(sum(value * value for value in document))

    if query_norm == 0 or document_norm == 0:
        return 0.0

    return dot_product / (query_norm * document_norm)

        WHERE UPPER(CAST(nct_id AS STRING)) IN UNNEST(@trial_ids)
    """

    client = bigquery.Client(
        project=settings.gcp_project,
        location=settings.bq_location,
    )

    query_job = None
    try:
        job_config = bigquery.QueryJobConfig(
            query_parameters=[
                bigquery.ArrayQueryParameter(
                    "trial_ids",
                    "STRING",
                    selected_trial_ids,
                )
            ]
        )

        query_job = client.query(sql, job_config=job_config)
        rows = query_job.result(timeout=settings.adk_timeout_seconds)
        ranked: list[dict[str, Any]] = []

        for row in rows:
            nct_id = str(row.get("nct_id") or "").upper()
            text = str(row.get("chunk_text") or "").strip()

            # Defend against unexpected or malformed rows.
            if nct_id not in selected_trial_ids or not text:
                continue

            score = _cosine_similarity(query_vector, row.get("embedding"))

            ranked.append(
                {
                    "chunk_id": str(row.get("chunk_id") or ""),
                    "nct_id": nct_id,
                    "section": str(row.get("chunk_type") or "Trial information"),
                    "text": text,
                    "score": score,
                    "metadata_json": row.get("metadata_json"),
                    "url": _get_trial_url(nct_id),
                }
            )

        return _select_evidence(ranked, selected_trial_ids)

    except Exception:
        try:
            if query_job is not None:
                query_job.cancel()
        except Exception:
            pass
        raise
    finally:
        client.close()


def _normalize_local_chunk(chunk: dict[str, Any]) -> dict[str, Any] | None:
    """Convert supported local chunk formats to one internal representation."""
    nct_id = str(chunk.get("nct_id") or "").strip().upper()

    text = str(
        chunk.get("chunk_text")
        or chunk.get("text")
        or chunk.get("content")
        or ""
    ).strip()

    if not re.fullmatch(r"NCT\d{8}", nct_id) or not text:
        return None

    return {
        "chunk_id": str(chunk.get("chunk_id") or ""),
        "nct_id": nct_id,
        "section": str(
            chunk.get("chunk_type")
            or chunk.get("section")
            or "Trial information"
        ),
        "text": text,
        "metadata_json": chunk.get("metadata_json"),
        "url": _get_trial_url(nct_id),
    }


def _retrieve_local_evidence(
    question: str,
    selected_trial_ids: list[str],
) -> list[dict[str, Any]]:
    """Fallback for local processed chunks when BigQuery has no matching rows."""
    selected = set(selected_trial_ids)
    ranked: list[dict[str, Any]] = []

    for chunk in chunks() or []:
        if not isinstance(chunk, dict):
            continue

        item = _normalize_local_chunk(chunk)
        if not item or item["nct_id"] not in selected:
            continue

        item["score"] = _lexical_score(question, item["text"])
        ranked.append(item)

    return _select_evidence(ranked, selected_trial_ids)


def _select_evidence(
    ranked: list[dict[str, Any]],
    selected_trial_ids: list[str],
) -> list[dict[str, Any]]:
    """Select the highest-ranked evidence while retaining trial coverage."""
    ranked.sort(key=lambda item: item.get("score", 0.0), reverse=True)

    per_trial_count: Counter[str] = Counter()
    selected: list[dict[str, Any]] = []
    seen: set[tuple[str, str]] = set()

    for item in ranked:
        nct_id = item["nct_id"]
        text = item["text"]
        dedupe_key = (nct_id, re.sub(r"\s+", " ", text).strip().lower())

        if dedupe_key in seen:
            continue

        if per_trial_count[nct_id] >= MAX_EVIDENCE_PER_TRIAL:
            continue

        seen.add(dedupe_key)
        selected.append(item)
        per_trial_count[nct_id] += 1

        if len(selected) >= MAX_TOTAL_EVIDENCE:
            break

    # Keep the selected-trial list available for downstream logic. Trials
    # with no retrieved passages are not given fabricated evidence.
    return selected


def retrieve_for_chat(
    question: str,
    trial_ids: list[str],
    top_k_per_trial: int = MAX_EVIDENCE_PER_TRIAL,
) -> list[dict[str, Any]]:
    """Retrieve ranked evidence for the user's selected trials.

    The optional top_k_per_trial argument is retained for compatibility with
    callers using the previous interface.
    """
    question = _validate_question(question)
    selected_trial_ids = _normalize_trial_ids(trial_ids)

    try:
        evidence = _retrieve_bigquery_evidence(question, selected_trial_ids)
        if evidence:
            return evidence

        logger.info(
            "No matching BigQuery chunks for selected trials; trying local chunks."
        )
    except Exception as exc:
        # Do not log the question, patient case, or retrieved medical text.
        log_safe_error(logger, request_id=None, step="chat_vector_search", error=exc)

    local_evidence = _retrieve_local_evidence(question, selected_trial_ids)

    if not local_evidence:
        logger.info("No evidence found for the selected trials.")

    return local_evidence


def build_evidence_from_candidates(
    candidates: list[dict[str, Any]],
) -> list[dict[str, Any]]:
    """Normalize retrieved passages into the evidence format used by the LLM."""
    result: list[dict[str, Any]] = []

    for candidate in candidates:
        nct_id = str(candidate.get("nct_id") or "").upper()
        text = remove_instruction_like_clauses(str(candidate.get("text") or ""))

        if not re.fullmatch(r"NCT\d{8}", nct_id) or not text:
            continue

        result.append(
            {
                "nct_id": nct_id,
                "section": str(candidate.get("section") or "Trial information"),
                "text": text[:MAX_EVIDENCE_CHARS],
                "url": _get_trial_url(nct_id),
                "score": candidate.get("score", 0.0),
            }
        )

    return result


async def answer_question(question: str, evidence: list[dict[str, Any]]) -> str:
    """Generate an evidence-grounded answer with the request-scoped ADK agent."""
    if not evidence:
        return (
            "I couldn't retrieve supporting text from the selected trials for "
            "this question. Try rephrasing it or selecting a trial with relevant "
            "information. I won't infer an answer without trial evidence."
        )

    return await answer_trial_question(question=question, evidence=evidence)


async def _chat_answer(
    question: str,
    trial_ids: list[str],
) -> dict[str, Any]:
    """Answer a question about selected trials and return citation metadata."""
    question = _validate_question(question)
    selected_trial_ids = _normalize_trial_ids(trial_ids)
    known_trial_ids = set(_trial_lookup())
    if any(trial_id not in known_trial_ids for trial_id in selected_trial_ids):
        raise ValueError("One or more selected trials are not available.")

    evidence = await asyncio.wait_for(
        asyncio.to_thread(retrieve_for_chat, question, selected_trial_ids),
        timeout=settings.adk_timeout_seconds,
    )
    # Defense in depth: never pass or cite content outside the selected IDs,
    # even if a storage query or fallback returns an unexpected row.
    evidence = [
        item for item in evidence
        if isinstance(item, dict)
        and str(item.get("nct_id") or "").strip().upper() in selected_trial_ids
    ]
    evidence = build_evidence_from_candidates(evidence)

    if not evidence:
        return {
            "answer": (
                "I couldn't find usable evidence in the selected trials for this "
                "question. Please try another question or verify that the selected "
                "trials have been indexed."
            ),
            "citations": [],
            "missing_info": (
                "No relevant trial passages were retrieved for the selected trials."
            ),
        }

    # Patient narratives are not needed for evidence-only trial chat.
    answer = await answer_question(question, evidence)
    trial_lookup = _trial_lookup()

    citations: list[dict[str, Any]] = []
    seen_citations: set[tuple[str, str, str]] = set()

    for item in evidence:
        nct_id = item["nct_id"]
        section = item["section"]
        excerpt = item["text"][:300].strip()

        citation_key = (nct_id, section, excerpt)
        if citation_key in seen_citations:
            continue

        seen_citations.add(citation_key)
        citations.append(
            {
                "nct_id": nct_id,
                "trial_title": _get_trial_title(nct_id, trial_lookup),
                "section": section,
                "excerpt": excerpt,
                "url": _get_trial_url(nct_id),
            }
        )

    return {
        "answer": answer,
        "citations": citations,
        "missing_info": None,
    }


async def chat_answer(
    question: str,
    trial_ids: list[str],
    patient_case: str | None = None,
) -> dict[str, Any]:
    """Run selected-trial chat with an overall timeout and no persistent memory."""
    return await asyncio.wait_for(
        _chat_answer(question, trial_ids),
        timeout=MAX_CHAT_SECONDS,
    )

from __future__ import annotations

import asyncio
import re
from typing import Any

from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer

from app.services.firebase_auth import verify_firebase_id_token

_bearer = HTTPBearer(auto_error=False)


async def require_firebase_user(
    credentials: HTTPAuthorizationCredentials | None = Depends(_bearer),
) -> dict[str, Any]:
    if credentials is None or credentials.scheme.lower() != "bearer":
        raise HTTPException(status_code=401, detail="A Firebase sign-in is required.")
    try:
        claims = await asyncio.to_thread(verify_firebase_id_token, credentials.credentials)
    except RuntimeError as exc:
        raise HTTPException(status_code=503, detail="Firebase authentication is not configured on the server.") from exc
    except Exception as exc:
        # Provider failures are deliberately not returned to callers. Missing
        # or invalid credentials must never fall through as an anonymous user.
        raise HTTPException(status_code=401, detail="The Firebase ID token is invalid or expired.") from exc
    uid = claims.get("uid") or claims.get("sub")
    if not isinstance(uid, str) or not re.fullmatch(r"[A-Za-z0-9:_-]{1,128}", uid):
        raise HTTPException(status_code=401, detail="The Firebase ID token has no valid user identity.")
    return {
        "uid": uid,
        "email": str(claims.get("email") or ""),
        "display_name": str(claims.get("name") or ""),
    }

    snapshot = _session_ref(uid, session_id).get()
    if not snapshot.exists:
        return None
    data = snapshot.to_dict() or {}
    messages = (
        snapshot.reference.collection("messages")
        .order_by("createdAt", direction="DESCENDING")
        .stream()
    )
    by_turn: dict[str, dict[str, Any]] = {}
    for message in reversed(list(messages)):
        item = message.to_dict() or {}
        turn_id = str(item.get("turnId") or message.id)
        turn = by_turn.setdefault(turn_id, {"question": "", "answer": "", "citations": [], "timestamp": None})
        if item.get("role") == "user":
            turn["question"] = str(item.get("content") or "")
        elif item.get("role") == "assistant":
            turn["answer"] = str(item.get("content") or "")
            turn["citations"] = item.get("trialReferences", [])
        turn["timestamp"] = _timestamp_value(item.get("createdAt")) or turn["timestamp"]
    return {
        "id": snapshot.id,
        "title": data.get("title") or "Untitled Session",
        "createdAt": _timestamp_value(data.get("createdAt")),
        "updatedAt": _timestamp_value(data.get("updatedAt")),
        "searchedAt": _timestamp_value(data.get("searchedAt")),
        "status": data.get("status", "draft"),
        "matchedTrialIds": data.get("matchedTrialIds", []),
        "searchQuery": data.get("searchQuery", ""),
        "data": data.get("resultSummary"),
        "chatHistory": list(by_turn.values()),
    }

"""Deterministic emergency and patient-fact safety checks."""

from __future__ import annotations

import json
import re
from pathlib import Path

from app.schemas import PatientProfile
from app.services.patient_parser import _validate_profile
from app.services.untrusted_text import remove_instruction_like_clauses

EMERGENCY_NOTICE = (
    "This description may indicate a medical emergency. Seek emergency care now, "
    "or contact local emergency services."
)
URGENT_SIGN_FILE = Path(__file__).resolve().parents[1] / "urgent_signs.json"

KEY_FACTS = {
    "diagnosis": "Main diagnosis or condition",
    "age": "Age",
    "prior_treatments": "Prior treatments",
    "key_findings": "Disease stage, biomarkers, or performance status",
}


def _config() -> dict[str, list[str]]:
    data = json.loads(URGENT_SIGN_FILE.read_text(encoding="utf-8"))
    signs = data["warning_signs"]
    negations = data["negation_terms"]
    if not isinstance(signs, list) or not signs or not isinstance(negations, list):
        raise ValueError("Urgent-sign configuration is invalid.")
    if any(not isinstance(item, str) or not item.strip() for item in signs + negations):
        raise ValueError("Urgent-sign configuration contains an invalid item.")
    return {"warning_signs": signs, "negation_terms": negations}


def screen_urgent_case(case: str) -> bool:
    """Return true for configured warning phrases not preceded by simple negation."""
    config = _config()
    for sign in config["warning_signs"]:
        for match in re.finditer(rf"(?<!\w){re.escape(sign)}(?!\w)", case, re.I):
            preceding = case[max(0, match.start() - 100):match.start()].casefold()
            clauses = re.split(r"[.;:,!?]|\b(?:but|however|although|yet|and)\b", preceding)
            clause = clauses[-1] if clauses else preceding
            words = re.findall(r"[a-z]+", clause)[-5:]
            window = " ".join(words)
            if any(
                re.search(rf"(?:^|\s){re.escape(term.casefold())}(?:$|\s)", window)
                for term in config["negation_terms"]
            ):
                continue
            if re.search(r"\bno\s+history\s+of\s*$", preceding):
                continue
            return True
    return False


def derive_missing_facts(profile: PatientProfile) -> list[str]:

    if not profile.prior_treatments:

def detect_supported_conflicts(case: str) -> tuple[list[str], list[str]]:
    """Detect simple conflicting ages/stages and return the values to exclude."""
    conflicts: list[str] = []
    excluded: list[str] = []

    ages = list(re.finditer(r"\b(\d{1,3})(?:\s*years?\s*old|-year-old|\s*yo)\b", case, re.I))
    ages.extend(re.finditer(r"\b(?:age|aged)\s+(\d{1,3})\b", case, re.I))
    age_values = list(dict.fromkeys(item.group(1) for item in ages))
    if len(age_values) > 1:
        conflicts.append("Conflicting ages are stated in the case.")
        excluded.extend(age_values)

    stages = list(re.finditer(r"\b(?:stage|stg\.?\s*)\s*(IV|III|II|I|4|3|2|1|0)([A-D]?)\b", case, re.I))
    stage_values = list(dict.fromkeys((item.group(1) + item.group(2)).upper() for item in stages))
    if len(stage_values) > 1:
        conflicts.append("Conflicting disease stages are stated in the case.")
        excluded.extend(stage_values)

    return conflicts, excluded


def remove_conflicting_fact_mentions(case: str, excluded_values: list[str]) -> str:
    """Remove age and stage statements whose values conflict in the case."""
    safe_case = case
    for value in excluded_values:
        escaped = re.escape(str(value))
        if value.isdigit():
            pattern = rf"\b(?:(?:age|aged)\s*)?{escaped}(?:\s*years?\s*old|-year-old|\s*yo)?\b"
        else:
            pattern = rf"\b(?:stage\s*|stg\.?\s*){escaped}[A-D]?\b"
        safe_case = re.sub(pattern, " [conflicting fact omitted] ", safe_case, flags=re.I)
    return " ".join(safe_case.split())


def validate_extracted_profile(profile: PatientProfile, case: str) -> PatientProfile:
    """Validate extracted facts and remove values involved in detected conflicts."""
    raw_primary_conditions = list(profile.primary_conditions)
    raw_key_findings = list(profile.key_findings)
    validated = _validate_profile(profile, case)
    conflicts, excluded = detect_supported_conflicts(case)
    stage_values = {
        value.casefold()
        for value in excluded
        if re.fullmatch(r"(?:IV|III|II|I|4|3|2|1|0)[A-D]?", value, re.I)
    }
    if stage_values:
        def remove_conflicting_stage(fact: str) -> str:
            for value in stage_values:
                fact = re.sub(
                    rf"\b(?:stage\s*|stg\.?\s*){re.escape(value)}\b",
                    " ",
                    fact,
                    flags=re.I,
                )
            return " ".join(fact.split()).strip(" ,;:-")

        for field_name in ("primary_conditions", "key_findings"):
            cleaned_facts = [
                remove_conflicting_stage(fact)
                for fact in (
                    raw_primary_conditions
                    if field_name == "primary_conditions"
                    else raw_key_findings
                )
            ]
            case_normalized = re.sub(r"[^a-z0-9]+", " ", case.casefold()).strip()
            supported_facts = [
                fact for fact in cleaned_facts
                if fact
                and re.sub(r"[^a-z0-9]+", " ", fact.casefold()).strip() in case_normalized
            ]
            existing = getattr(validated, field_name)
            setattr(validated, field_name, list(dict.fromkeys([*existing, *supported_facts])))
    if any(conflict.startswith("Conflicting ages") for conflict in conflicts):
        validated.age_years = None

    query_facts = list(dict.fromkeys([
        *validated.primary_conditions,
        *validated.key_findings,
        *validated.prior_treatments,
        *validated.current_medications,
    ]))
    validated.search_query = (
        " ".join(query_facts)
        or remove_instruction_like_clauses(
            remove_conflicting_fact_mentions(case, excluded)
        )
    )[:2000]
    return validated


def safe_search_query(query: str, case: str, profile: PatientProfile) -> str:
    """Accept only text grounded in the sanitized case; preserve stable wording."""
    clean_case = " ".join(remove_instruction_like_clauses(case).split())
    query = " ".join(remove_instruction_like_clauses(str(query or "")).split())[:2000]
    source_terms = set(re.findall(r"[a-z0-9]+", clean_case.casefold()))
    terms = re.findall(r"[a-z0-9]+", query.casefold())
    if terms and all(term in source_terms for term in terms):
        return query

    # Sanitization can remove an entire model-proposed query when it contains
    # an instruction-like clause. Fall back to already-validated profile facts.
    supported_facts = [
        *profile.primary_conditions,
        *profile.comorbidities,
        *profile.current_medications,
        *profile.prior_treatments,
        *profile.key_findings,
    ]
    fallback = " ".join(
        fact for fact in supported_facts
        if fact and re.search(
            rf"(?<![a-z0-9]){re.escape(fact.casefold())}(?![a-z0-9])",
            clean_case.casefold(),
        )
    )
    if fallback:
        return fallback[:2000]
    raise ValueError("Search query contains unsupported facts.")

"""Google Cloud Storage helpers for JSON-based clinical-trial data."""

from __future__ import annotations

import json
import logging
from typing import Any

from google.api_core.exceptions import NotFound
from google.cloud import storage

from app.config import settings

logger = logging.getLogger(__name__)


def _get_bucket_name() -> str:
    bucket_name = str(settings.gcs_bucket or "").strip()

    if not bucket_name:
        raise RuntimeError(
            "GCS_BUCKET is not configured. Set it in the environment."
        )

    return bucket_name


def _get_object_name(filename: str) -> str:
    """Resolve an object name relative to the configured GCS prefix."""
    if not isinstance(filename, str) or not filename.strip():
        raise ValueError("A non-empty GCS object name is required.")

    object_name = filename.strip().replace("\\", "/").lstrip("/")

    parts = object_name.split("/")
    if any(part in {"", ".", ".."} for part in parts):
        raise ValueError("Invalid GCS object path.")

    prefix = str(settings.gcs_prefix or "").strip("/")
    if prefix:
        # Avoid adding the prefix twice when callers already provide it.
        if object_name == prefix or object_name.startswith(prefix + "/"):
            return object_name

        return f"{prefix}/{object_name}"

    return object_name


def read_json(filename: str) -> Any | None:
    """Read and decode a JSON object.

    Returns None only when the requested object does not exist.
    Authentication, permission, network, and JSON errors are raised.
    """
    bucket_name = _get_bucket_name()
    object_name = _get_object_name(filename)

    client = storage.Client(project=settings.gcp_project)

    try:
        blob = client.bucket(bucket_name).blob(object_name)

        try:
            content = blob.download_as_text(encoding="utf-8")
        except NotFound:
            logger.info("step=gcs_read result=not_found")
            return None

        try:
            return json.loads(content)
        except json.JSONDecodeError as exc:
            logger.error("step=gcs_read error_category=InvalidJSON")
            raise ValueError(
                f"GCS object '{object_name}' does not contain valid JSON."
            ) from exc

    finally:
        client.close()


def write_json(
    filename: str,
    data: Any,
    *,
    overwrite: bool = True,
) -> str:
    """Serialize and upload JSON to GCS.

    Args:
        filename: Object name relative to GCS_PREFIX, or a fully prefixed name.
        data: JSON-serializable Python data.
        overwrite: If False, fail if the object already exists.

    Returns:
        The fully resolved GCS object name.
    """
    bucket_name = _get_bucket_name()
    object_name = _get_object_name(filename)

    try:
        content = json.dumps(
            data,
            ensure_ascii=False,
            indent=2,
            allow_nan=False,
        )
    except (TypeError, ValueError) as exc:
        raise ValueError("The supplied data cannot be serialized as valid JSON.") from exc

    client = storage.Client(project=settings.gcp_project)

    try:
        blob = client.bucket(bucket_name).blob(object_name)

        # A generation precondition prevents accidental overwrites.
        if overwrite:
            blob.upload_from_string(
                content,
                content_type="application/json; charset=utf-8",
            )
        else:
            blob.upload_from_string(
                content,
                content_type="application/json; charset=utf-8",
                if_generation_match=0,
            )

        logger.info("step=gcs_write result=success")
        return object_name

    finally:
        client.close()


def object_exists(filename: str) -> bool:
    """Check whether a GCS object exists."""
    bucket_name = _get_bucket_name()
    object_name = _get_object_name(filename)

    client = storage.Client(project=settings.gcp_project)

    try:
        return client.bucket(bucket_name).blob(object_name).exists()
    finally:
        client.close()


def delete_object(filename: str) -> bool:
    """Delete an object if it exists.

    Returns True when deleted and False when the object was absent.
    """
    bucket_name = _get_bucket_name()
    object_name = _get_object_name(filename)

    client = storage.Client(project=settings.gcp_project)

    try:
        blob = client.bucket(bucket_name).blob(object_name)

        try:
            blob.delete()
            logger.info("step=gcs_delete result=success")
            return True
        except NotFound:
            return False

    finally:
        client.close()

def parse_age(s: str | None):
    if not s:
        return None
    m = re.match(r"(\d+(?:\.\d+)?)\s*(year|month|week|day)", s.lower())
    if not m:
        return None
    v, unit = float(m.group(1)), m.group(2)
    return v / {"year": 1, "month": 12, "week": 52, "day": 365}[unit]


def flatten(study: dict) -> dict | None:
    p = study.get("protocolSection", {})
    ident, st, desc = p.get("identificationModule", {}), p.get("statusModule", {}), p.get("descriptionModule", {})
    el, dm, cm = p.get("eligibilityModule", {}), p.get("designModule", {}), p.get("conditionsModule", {})
    ai, cl, sp = p.get("armsInterventionsModule", {}), p.get("contactsLocationsModule", {}), p.get("sponsorCollaboratorsModule", {})
    refs = p.get("referencesModule", {}).get("references", [])
    if not el.get("eligibilityCriteria") or not desc.get("briefSummary"):
        return None
    return {
        "nct_id": ident["nctId"],
        "title": ident.get("briefTitle", ""),
        "official_title": ident.get("officialTitle", ""),
        "status": st.get("overallStatus", ""),
        "phases": dm.get("phases", []),
        "study_type": dm.get("studyType", ""),
        "conditions": cm.get("conditions", []),
        "keywords": cm.get("keywords", []),
        "brief_summary": desc["briefSummary"],
        "interventions": [i.get("name", "") for i in ai.get("interventions", [])],

        "sex": el.get("sex", "ALL"),

def fetch_area(area: str, want: int, seen: set) -> list[dict]:
    out, token = [], None
    while len(out) < want:
        params = {"query.cond": area, "filter.overallStatus": "RECRUITING", "pageSize": 50, "format": "json"}
        if token:
            params["pageToken"] = token
        r = requests.get(API, params=params, timeout=60)
        r.raise_for_status()
        j = r.json()
        for s in j.get("studies", []):
            rec = flatten(s)
            if rec and rec["nct_id"] not in seen:
                seen.add(rec["nct_id"])
                out.append(rec)
                if len(out) >= want:
                    break
        token = j.get("nextPageToken")
        if not token:
            break
        time.sleep(0.3)
    return out

import re

MAX_CHARS = 1800


def split_eligibility(text: str) -> tuple[str, str]:
    m = re.search(r"exclusion criteria\s*:?", text, re.I)
    if m:
        return text[: m.start()].strip(), text[m.end():].strip()
    return text.strip(), ""


def window(text: str, size: int = MAX_CHARS) -> list[str]:
    out, cur = [], ""
    for line in text.split("\n"):
        if cur and len(cur) + len(line) + 1 > size:
            out.append(cur.strip())
            cur = ""
        cur += line + "\n"
    if cur.strip():
        out.append(cur.strip())
    return out


def chunk_trial(t: dict) -> list[dict]:
    head = f"Trial: {t['title']}\nConditions: {', '.join(t['conditions'])}\n"
    chunks = [{
        "id": f"{t['nct_id']}::overview::0", "nct_id": t["nct_id"], "type": "overview",
        "text": head + f"Phase: {', '.join(t['phases']) or 'N/A'}\n"
                       f"Interventions: {', '.join(t['interventions'][:8])}\nSummary: {t['brief_summary'][:1500]}",
    }]
    inc, exc = split_eligibility(t["eligibility_text"])
    for kind, body in (("inclusion", inc), ("exclusion", exc)):
        for i, piece in enumerate(window(body) if body else []):
            chunks.append({"id": f"{t['nct_id']}::{kind}::{i}", "nct_id": t["nct_id"], "type": kind,
                           "text": head + f"{kind.upper()} CRITERIA:\n{piece}"})
    for i, pub in enumerate(t.get("publications", [])):
        chunks.append({"id": f"{t['nct_id']}::publication::{i}", "nct_id": t["nct_id"], "type": "publication",
                       "text": head + f"Publication ({pub['pmcid']}): {pub['title']}\n{pub['abstract'][:1500]}"})
    return chunks

"""BigQuery Vector Search Table and Index Initializer.

Initializes the BigQuery dataset and trial_chunks table.
In BigQuery, exact brute-force vector search requires NO vector index or

def init_bigquery_resources(create_index: bool = False) -> None:
    """Initialize BigQuery dataset and trial_chunks table."""
    client = bigquery.Client(project=settings.gcp_project, location=settings.bq_location)
    dataset_ref = bigquery.DatasetReference(settings.gcp_project, settings.bigquery_dataset)

    # 1. Dataset
    try:
        client.get_dataset(dataset_ref)
        logger.info(f"Dataset '{settings.bigquery_dataset}' already exists in location '{settings.bq_location}'.")
    except NotFound:
        logger.info(f"Creating dataset '{settings.bigquery_dataset}' in location '{settings.bq_location}'...")
        ds = bigquery.Dataset(dataset_ref)
        ds.location = settings.bq_location
        ds.description = "Clinical Trial RAG embeddings, chunks, and metadata"
        client.create_dataset(ds)
        logger.info(f"Created dataset '{settings.bigquery_dataset}'.")

    # 2. Table
    table_ref = dataset_ref.table(settings.bigquery_chunks_table)
    schema = [
        bigquery.SchemaField("chunk_id", "STRING", mode="REQUIRED", description="Unique chunk ID"),
        bigquery.SchemaField("nct_id", "STRING", mode="REQUIRED", description="NCT identifier"),
        bigquery.SchemaField("chunk_text", "STRING", mode="REQUIRED", description="Text content"),
        bigquery.SchemaField("chunk_type", "STRING", mode="NULLABLE", description="Type of chunk"),
        bigquery.SchemaField("embedding", "FLOAT64", mode="REPEATED", description="Dense embedding vector"),
        bigquery.SchemaField("metadata_json", "STRING", mode="NULLABLE", description="JSON trial metadata"),
    ]

    try:
        table = client.get_table(table_ref)
        logger.info(f"Table '{settings.bigquery_chunks_table}' already exists.")
    except NotFound:
        logger.info(f"Creating table '{settings.bigquery_chunks_table}'...")
        table = bigquery.Table(table_ref, schema=schema)
        table.description = "Stores trial chunk texts and dense vector embeddings for vector search"
        table = client.create_table(table)
        logger.info(f"Created table '{settings.bigquery_chunks_table}'.")

    logger.info("BigQuery resources initialized successfully.")
    logger.info("Exact brute-force vector search is ready without deploying an endpoint.")

    # 3. Optional Approximate Nearest Neighbor Vector Index (Opt-in)
    if create_index:
        logger.info("Creating optional BigQuery vector index...")
        sql = f"""
        CREATE VECTOR INDEX IF NOT EXISTS trial_chunks_vector_idx
        ON `{table_ref.project}.{table_ref.dataset_id}.{table_ref.table_id}`(embedding)
        OPTIONS(distance_type='COSINE', index_type='IVF');
        """
        job = client.query(sql, location=settings.bq_location)
        job.result()
        logger.info("BigQuery vector index created.")


if __name__ == "__main__":
    init_bigquery_resources(create_index=False)

def validate_records(
    records: list[dict[str, Any]],
    expected_dim: int,
) -> tuple[list[dict[str, Any]], list[dict[str, Any]]]:
    """Validate each chunk and embedding record."""
    valid: list[dict[str, Any]] = []
    rejected: list[dict[str, Any]] = []

    for record in records:
        chunk_id = record.get("chunk_id")
        nct_id = record.get("nct_id")
        text = record.get("chunk_text")
        embedding = record.get("embedding")

        if not chunk_id or not nct_id or not text or not text.strip():
            logger.warning(
                "Rejecting record %s: missing ID, NCT, or text.",
                chunk_id,
            )
            rejected.append({
                "record": record,
                "reason": "Missing required field or empty text",
            })
            continue

        if (
            not isinstance(embedding, (list, tuple))
            or len(embedding) != expected_dim
        ):
            dimension = len(embedding) if embedding else 0
            logger.warning(
                "Rejecting record %s: invalid embedding dimension %s.",
                chunk_id,
                dimension,
            )
            rejected.append({
                "record": record,
                "reason": f"Dimension mismatch (expected {expected_dim})",
            })
            continue

        if any(
            value is None or not math.isfinite(value)
            for value in embedding
        ):
            logger.warning(
                "Rejecting record %s: embedding contains NaN, Inf, or None.",
                chunk_id,
            )
            rejected.append({
                "record": record,
                "reason": "Non-finite values in embedding",
            })
            continue

        valid.append(record)

    return valid, rejected


def get_existing_chunk_ids(
    client: bigquery.Client,
    table_ref: bigquery.TableReference,
) -> set[str]:
    """Fetch existing chunk IDs from BigQuery to prevent duplicate processing."""
    query = (

    try:

    except Exception:

        logger.exception("Could not fetch existing chunk IDs; stopping ingestion.")
        raise


def upload_processed_json_to_gcs(filename: str) -> str:

        logger.error(
            "Source trials file not found at %s. Run fetch_trials.py first.",
            trials_path,
        )
        sys.exit(1)

    with trials_path.open("r", encoding="utf-8") as file:
        trials = json.load(file)

    # 1. Create chunks from the source trials.
    all_chunks = [
        chunk
        for trial in trials
        for chunk in chunk_trial(trial)
    ]
    logger.info("Loaded %s trials -> %s chunks.", len(trials), len(all_chunks))

    client = bigquery.Client(
        project=settings.gcp_project,
        location=settings.bq_location,
    )

    try:
        table = ensure_table_exists(client)
        table_ref = table.reference

        # 2. Skip chunks already stored in BigQuery unless --refresh is explicit.
        if refresh:
            logger.warning(
                "Explicit --refresh flag specified: full table refresh requested."
            )
            chunks_to_process = all_chunks
        else:
            existing_ids = get_existing_chunk_ids(client, table_ref)
            chunks_to_process = [
                chunk for chunk in all_chunks
                if chunk["id"] not in existing_ids
            ]
            skipped_count = len(all_chunks) - len(chunks_to_process)
            logger.info(
                "Duplicate check: %s chunks exist in BigQuery; "
                "%s already present, %s new chunks to embed.",
                len(existing_ids),
                skipped_count,
                len(chunks_to_process),
            )

        valid_records: list[dict[str, Any]] = []

        # 3. Generate embeddings only for chunks not already in BigQuery.
        if chunks_to_process:
            logger.info(
                "Generating embeddings via Vertex AI for %s chunks...",
                len(chunks_to_process),
            )
            chunk_texts = [chunk["text"] for chunk in chunks_to_process]
            vectors: list[list[float]] = []

            for start in range(0, len(chunk_texts), batch_size):
                batch = chunk_texts[start:start + batch_size]
                batch_vectors = embed(batch, task_type="RETRIEVAL_DOCUMENT")

                if len(batch_vectors) != len(batch):
                    raise RuntimeError(
                        "Embedding count does not match batch size; "
                        "stopping before BigQuery insertion."
                    )

                vectors.extend(batch_vectors)
                logger.info(
                    "Embedded %s/%s chunks.",
                    min(start + len(batch), len(chunk_texts)),
                    len(chunk_texts),
                )

            trial_map = {
                trial["nct_id"]: trial
                for trial in trials
                if trial.get("nct_id")
            }
            records: list[dict[str, Any]] = []

            for chunk, vector in zip(chunks_to_process, vectors):
                trial = trial_map.get(chunk["nct_id"], {})
                metadata = {
                    "title": trial.get("title", ""),
                    "status": trial.get("status", ""),
                    "phases": trial.get("phases", []),
                    "conditions": trial.get("conditions", []),
                    "sponsor": trial.get("sponsor"),
                    "study_url": (
                        "https://clinicaltrials.gov/study/"
                        f"{trial.get('nct_id', '')}"
                    ),
                }
                records.append({
                    "chunk_id": chunk["id"],
                    "nct_id": chunk["nct_id"],
                    "chunk_text": chunk["text"],
                    "chunk_type": chunk.get("type", "overview"),
                    "embedding": vector,
                    "metadata_json": json.dumps(
                        metadata,
                        ensure_ascii=False,
                    ),
                })

            # 4. Validate all generated records before insertion.
            valid_records, rejected_records = validate_records(
                records,
                expected_dim=settings.embedding_dim,
            )
            logger.info(
                "Validation: %s valid records, %s rejected records.",
                len(valid_records),
                len(rejected_records),
            )

            if rejected_records:
                logger.warning(
                    "%s records were rejected and will not be inserted.",
                    len(rejected_records),
                )

            if not valid_records:
                logger.error("No valid records to write to BigQuery. Aborting.")
                return
        else:
            logger.info(
                "All chunks already exist in BigQuery. "
                "Skipping embedding generation and insertion."
            )

        # 5. Insert records. Full table refresh happens only with --refresh.
        if valid_records:
            write_disposition = (
                bigquery.WriteDisposition.WRITE_TRUNCATE
                if refresh
                else bigquery.WriteDisposition.WRITE_APPEND
            )
            logger.info(
                "Loading %s chunks into BigQuery `%s.%s.%s`...",
                len(valid_records),
                table_ref.project,
                table_ref.dataset_id,
                table_ref.table_id,
            )
            job_config = bigquery.LoadJobConfig(
                schema=table.schema,
                write_disposition=write_disposition,
            )
            load_job = client.load_table_from_json(
                valid_records,
                table_ref,
                job_config=job_config,
            )
            load_job.result()
            logger.info(
                "Successfully loaded %s chunks into BigQuery.",
                len(valid_records),
            )
        else:
            logger.info("No new records to insert into BigQuery.")

        # 6. Update local chunks.json cache.
        chunks_metadata = {
            chunk["id"]: {
                "nct_id": chunk["nct_id"],
                "type": chunk.get("type", "overview"),
                "text": chunk["text"],
            }
            for chunk in all_chunks
        }
        chunks_path = settings.processed_dir / "chunks.json"
        with chunks_path.open("w", encoding="utf-8") as file:
            json.dump(chunks_metadata, file, ensure_ascii=False)
        logger.info("Updated local chunks cache at %s.", chunks_path)

        # 7. Upload processed JSON files to GCS using the implemented helper.
        if settings.gcs_bucket:
            for filename in ("trials.json", "chunks.json"):
                try:
                    object_name = upload_processed_json_to_gcs(filename)
                    logger.info("Uploaded %s to GCS: %s", filename, object_name)
                except Exception:
                    logger.exception(
                        "GCS upload failed for %s. BigQuery processing has "
                        "already completed; fix the GCS issue and retry upload.",
                        filename,
                    )
                    raise
        else:
            logger.info("GCS_BUCKET is not configured; skipping GCS uploads.")

        logger.info("Ingestion completed successfully.")
    finally:
        client.close()


if __name__ == "__main__":
    parser = argparse.ArgumentParser(

/**

 * @property {number} latency_seconds
 * @property {string|null} [emergency_notice] Present when urgent screening stops matching.
 * @property {string[]} [missing_key_facts] Plain-language facts absent from the validated profile.
 * @property {string[]} [conflicting_facts] Conflicts detected in supported case text.
 * @property {Array<{nct_id: string, title: string, reason: string}>} [ruled_out_trials]
 * @property {string|null} [result_message] Search-specific empty-state explanation.

/**
 * @typedef {Object} ChatResponse
 * @property {string} answer
 * @property {Array<Object>} citations
 * @property {string|null} missing_info
 * @property {string|null} session_id Client-provided identifier; not server-side memory.
 */

async function request(endpoint, options = {}) {
  let response;

  try {
    response = await fetch(`${API_BASE}${endpoint}`, {
      ...options,
      headers: {
        "Content-Type": "application/json",
        ...(auth?.currentUser
          ? { Authorization: `Bearer ${await auth.currentUser.getIdToken()}` }
          : {}),
        ...options.headers,
      },
    });
  } catch (error) {
    throw new Error(
      "Cannot connect to the backend server. Please verify that FastAPI is running on http://localhost:8000."
    );
  }

  const raw = await response.text();
  let data;

  try {
    data = raw ? JSON.parse(raw) : {};
  } catch {
    throw new Error(
      `The server returned an invalid response: ${raw.slice(0, 200)}`
    );
  }

  if (!response.ok) {
    const detail = data?.detail || data?.message || raw;
    throw new Error(
      typeof detail === "string" ? detail : JSON.stringify(detail)
    );
  }

  return data;
}

const AuthContext = createContext(null);

async function loadProfile(firebaseUser) {
  const token = await firebaseUser.getIdToken();
  const response = await fetch(`${API_BASE}/api/auth/profile`, {
    headers: { Authorization: `Bearer ${token}` },
  });
  if (!response.ok) {
    throw new Error(response.status === 503
      ? "User profile storage is unavailable. Check Firebase Admin and Firestore setup."
      : "Could not load your user profile. Please retry sign-in.");
  }
  return response.json();
}

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    if (!auth) {
      setLoading(false);
      return undefined;
    }
    let mounted = true;
    const unsubscribe = onAuthStateChanged(auth, async (firebaseUser) => {
      setUser(null);
      setError("");
      if (!firebaseUser) {
        setLoading(false);
        return;
      }
      setLoading(true);
      try {
        const profile = await loadProfile(firebaseUser);
        if (mounted) setUser({ firebaseUser, profile });
      } catch (loadError) {
        if (mounted) setError(loadError.message || "Could not load your profile.");
      } finally {
        if (mounted) setLoading(false);
      }
    });
    return () => {
      mounted = false;
      unsubscribe();
    };
  }, []);

  const value = useMemo(() => ({
    user,
    loading,
    error,
    configured: isFirebaseConfigured,
    signIn: (email, password) => signInWithEmailAndPassword(auth, email, password),
    signUp: async (displayName, email, password) => {
      const credential = await createUserWithEmailAndPassword(auth, email, password);
      await updateProfile(credential.user, { displayName });
      await credential.user.getIdToken(true);
      const profile = await initializeProfile(displayName);
      setUser({ firebaseUser: credential.user, profile });
      return credential;
    },
    signOut: () => signOut(auth),
    retryProfile: async () => {
      if (!auth?.currentUser) return;
      setLoading(true);
      setError("");
      try {
        const profile = await loadProfile(auth.currentUser);
        setUser({ firebaseUser: auth.currentUser, profile });
      } catch (loadError) {
        setError(loadError.message || "Could not load your profile.");
      } finally {
        setLoading(false);
      }
    },
  }), [user, loading, error]);

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const value = useContext(AuthContext);
  if (!value) throw new Error("useAuth must be used within AuthProvider.");
  return value;
}

import { useState, useEffect, useCallback, useMemo, useRef } from "react";
import {
  clearRemoteSessions,
  createSession as createRemoteSession,
  deleteRemoteSession,
  getSession,
  listSessions,
  renameRemoteSession,
} from "../api";
import { clearAllStorage } from "../utils/storage";

function normalizeSession(session) {
  return {
    id: session.id,
    title: session.title || "New Patient Session",
    patientCase: session.searchQuery || "",
    data: session.data || null,
    activeTab: 0,
    chatHistory: session.chatHistory || [],
    createdAt: session.createdAt || Date.now(),
    updatedAt: session.updatedAt || Date.now(),
  };
}

export function useSessionManager(user) {
  const [sessions, setSessions] = useState([]);
  const [activeSessionId, setActiveSessionId] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");
  const [loadingSessionId, setLoadingSessionId] = useState(null);
  const switchRequest = useRef(0);

  useEffect(() => {
    let mounted = true;
    clearAllStorage(); // remove legacy per-tab cases/chat before loading user data
    setSessions([]);
    setActiveSessionId(null);
    setLoading(true);
    setError("");
    (async () => {
      try {
        let loaded = await listSessions();
        if (!Array.isArray(loaded)) loaded = [];
        if (loaded.length === 0) {
          loaded = [await createRemoteSession()];
        }
        if (!mounted) return;
        const normalized = loaded.map(normalizeSession);
        setSessions(normalized);
        const first = normalized[0];
        setActiveSessionId(first.id);
        const details = await getSession(first.id);
        if (mounted) {
          setSessions((current) => current.map((item) => item.id === first.id
            ? { ...item, ...normalizeSession(details) }
            : item));
        }
      } catch (loadError) {
        if (mounted) setError(loadError.message || "Could not load saved sessions.");
      } finally {
        if (mounted) setLoading(false);
      }
    })();
    return () => { mounted = false; };
  }, [user?.firebaseUser?.uid]);

  const activeSession = useMemo(
    () => sessions.find((session) => session.id === activeSessionId) || null,
    [sessions, activeSessionId],
  );

  const switchSession = useCallback(async (id) => {
    const requestId = ++switchRequest.current;
    setLoadingSessionId(id);
    setError("");
    try {
      const detail = await getSession(id);
      if (requestId !== switchRequest.current) return;
      setSessions((current) => current.map((item) => item.id === id
        ? { ...item, ...normalizeSession(detail) }
        : item));
      setActiveSessionId(id);
      return true;
    } catch (loadError) {
      if (requestId === switchRequest.current) setError(loadError.message || "Could not open this session.");
      return false;
    } finally {
      if (requestId === switchRequest.current) setLoadingSessionId(null);
    }
  }, []);

  const createNewSession = useCallback(async (title) => {
    switchRequest.current += 1;
    setLoadingSessionId(null);
    setError("");
    try {
      const created = normalizeSession(await createRemoteSession(title));
      setSessions((current) => [created, ...current]);
      setActiveSessionId(created.id);
      setError("");
      return created;
    } catch (createError) {
      setError(createError.message || "Could not create a session.");
      throw createError;
    }
  }, []);

  const updateSession = useCallback((id, patch) => {
    if (!id) return;
    const { touch = false, ...sessionPatch } = patch;
    setSessions((current) => {
      const next = current.map((session) => {
        if (session.id !== id) return session;
        const updated = { ...session, ...sessionPatch, updatedAt: new Date().toISOString() };
        if (sessionPatch.title && sessionPatch.title !== session.title) {
          renameRemoteSession(id, sessionPatch.title).catch((renameError) => {
            setError(renameError.message || "Could not save the session name.");
          });
        }
        return updated;
      });
      if (touch || sessionPatch.data || sessionPatch.chatHistory || sessionPatch.title) {
        next.sort((a, b) => new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime());
      }
      return next;
    });
  }, []);

  const updateActiveSession = useCallback((patch) => {
    updateSession(activeSessionId, patch);
  }, [activeSessionId, updateSession]);

  const renameSession = useCallback(async (id, title) => {
    const cleanTitle = title?.trim().slice(0, 100);
    if (!cleanTitle) return;
    try {
      await renameRemoteSession(id, cleanTitle);
      setSessions((current) => {
        const renamed = current.map((item) => item.id === id
          ? { ...item, title: cleanTitle, updatedAt: new Date().toISOString() }
          : item);
        return renamed.sort((a, b) => new Date(b.updatedAt).getTime() - new Date(a.updatedAt).getTime());
      });
    } catch (renameError) {
      setError(renameError.message || "Could not rename this session.");
    }
  }, []);

  const deleteSession = useCallback(async (id) => {
    try {
      await deleteRemoteSession(id);
      let remaining = sessions.filter((item) => item.id !== id);
      if (remaining.length === 0) remaining = [normalizeSession(await createRemoteSession())];
      setSessions(remaining);
      if (activeSessionId === id) setActiveSessionId(remaining[0].id);
    } catch (deleteError) {
      setError(deleteError.message || "Could not delete this session.");
    }
  }, [sessions, activeSessionId]);

  const clearAllSessions = useCallback(async () => {
    try {
      await clearRemoteSessions();
      const fresh = normalizeSession(await createRemoteSession());
      setSessions([fresh]);
      setActiveSessionId(fresh.id);
    } catch (clearError) {
      setError(clearError.message || "Could not clear saved sessions.");
    }
  }, []);

  return {
    sessions,
    activeSessionId,
    activeSession,
    loading,
    loadingSessionId,
    error,
    switchSession,
    createNewSession,
    updateActiveSession,
    updateSession,
    renameSession,
    deleteSession,
    clearAllSessions,
  };
}

# Cloud Run deployment

This project deploys as two Cloud Run services: the FastAPI API and the React static application. The deployment script uses Cloud Build from the Dockerfiles and keeps the local Firebase web configuration in ignored `frontend/.env`.

## Prerequisites

1. Install Google Cloud CLI, Node.js 20+, and npm.
2. Sign in with `gcloud auth login` and use an account allowed to deploy Cloud Run services, use Cloud Build and Artifact Registry, and enable APIs in the target project.
3. Configure `frontend/.env` using `frontend/.env.example`. Do not commit this file. Set the Firebase web app values for the Firebase project already used by the application.
4. Configure `backend/.env` with the GCP project that owns the existing BigQuery dataset, Vertex AI access, and optional GCS trial data. The script reads `GCP_PROJECT` from this ignored file; it defaults to the Cloud Run project if absent.

## Deploy

From the repository root in PowerShell:

```powershell
./deploy/deploy-cloud-run.ps1
```

The default Cloud Run target is `quiet-terminal-422106` in `us-central1`. Override the project, region, service names, and runtime service account as needed:

```powershell
./deploy/deploy-cloud-run.ps1 -ProjectId "your-cloud-run-project" -Region "us-central1" -RuntimeServiceAccount "clinical-trial-runtime@your-cloud-run-project.iam.gserviceaccount.com"
```

The script deploys the API first, builds the frontend with that API URL, deploys the web service, then sets API CORS to the web service origin. Both services are internet reachable so users can load the UI and Firebase-authenticated requests can reach the API. Protected API endpoints still verify Firebase ID tokens.

## Runtime identity permissions

Cloud Run uses its runtime service account and Application Default Credentials; do not upload a service-account key. Grant the runtime identity only the roles needed for configured services:

- Firestore access in the Firebase project used by `FIREBASE_PROJECT_ID` (typically `roles/datastore.user`).
- BigQuery job execution and read access to the configured dataset (typically `roles/bigquery.jobUser` and dataset-level `roles/bigquery.dataViewer`).
- Vertex AI model access in the project configured by `GCP_PROJECT` (typically `roles/aiplatform.user`).
- `roles/storage.objectViewer` on the trial-data bucket only when `GCS_BUCKET` is configured.

If Firebase, BigQuery, Vertex AI, or GCS belongs to another project, grant access on that resource's project. Keep `FIREBASE_PROJECT_ID` and `GCP_PROJECT` set to the projects that own those resources; they do not have to match the Cloud Run deployment project.

After deployment, open the printed web URL and check the printed `/api/ready` URL. Read API logs with:

```powershell
gcloud run services logs read clinical-trial-api --project quiet-terminal-422106 --region us-central1
```

# Clinical Trial RAG: File Flow and Responsibilities

This guide follows a request from the user's browser through the backend and cloud services, then maps the main files to their jobs. It describes the current repository implementation.

## 1. System at a glance

```mermaid
flowchart LR
    User[Clinical technician] --> Browser
    subgraph Frontend[React frontend]
        Browser[main.jsx mounts app] --> Auth[AuthContext and AuthScreen]
        Auth --> App[App.jsx workspace]
        App --> Hook[useSessionManager]
        App --> API[api.js authenticated HTTP client]
        Hook --> API
        API --> Views[Results, assessment, and chat components]
    end
    API -->|HTTPS + Firebase ID token| FastAPI[backend/app/main.py]
    subgraph Backend[FastAPI backend]
        FastAPI --> AuthCheck[auth_dependency.py]
        AuthCheck --> Token[firebase_auth.py]
        FastAPI --> Routes[schemas.py request and response validation]
        FastAPI --> Pipeline[pipeline.py input checks and urgent screen]
        Pipeline --> Workflow[agents/workflow.py orchestration]
        Workflow --> Tasks[agents/tasks.py model task instructions]
        Tasks --> Runtime[agents/adk_runtime.py structured model calls]
        Workflow --> Retriever[services/retriever.py]
        Retriever --> Embed[services/embeddings.py]
        Workflow --> Judge[services/eligibility_judge.py evidence checks and verdict]
        FastAPI --> UserData[services/user_data.py]
        FastAPI --> Chat[services/chat.py]
        Workflow --> TrialStore[services/trial_store.py]
    end
    Token --> Firebase[Firebase Authentication]
    UserData --> Firestore[(Cloud Firestore: user sessions and chat)]
    Embed --> Vertex[Vertex AI embeddings]
    Retriever --> BigQuery[(BigQuery: trial chunks and vectors)]
    Runtime --> Gemini[Gemini through Google ADK]
    TrialStore --> Files[Processed JSON files]
    TrialStore -. optional copy .-> GCS[Cloud Storage]
```

## 2. What happens when a user searches

```mermaid
sequenceDiagram
    actor Technician
    participant UI as App.jsx
    participant Hook as useSessionManager.js
    participant Client as api.js
    participant Route as main.py
    participant Auth as auth_dependency.py / firebase_auth.py
    participant Store as user_data.py / Firestore
    participant Pipe as pipeline.py
    participant Flow as agents/workflow.py
    participant Search as retriever.py / embeddings.py / BigQuery
    participant AI as tasks.py / adk_runtime.py / Gemini
    participant Judge as eligibility_judge.py

    Technician->>UI: Enter a de-identified case and submit
    UI->>Hook: Select or create a session
    UI->>Client: matchPatient(case, sessionId)
    Client->>Client: Add Firebase ID token
    Client->>Route: POST /api/match
    Route->>Auth: Verify token and obtain UID
    Route->>Store: Check session ownership; save query
    Route->>Pipe: Validate case and screen urgent phrases
    Pipe->>Flow: Start matching if screening allows it
    Flow->>AI: Extract supported patient facts
    AI-->>Flow: Structured profile
    Flow->>Search: Retrieve candidate trial chunks
    Search-->>Flow: Ranked trial candidates
    opt No candidate or weak retrieval
        Flow->>AI: Propose one profile-grounded refinement
        Flow->>Search: Run at most one additional retrieval
        Search-->>Flow: Merge and deduplicate candidates
    end
    loop For shortlisted candidates (bounded)
        Flow->>AI: Assess trial criteria using supplied record text
        AI-->>Flow: Proposed criteria, quotes, and explanations
        Flow->>Judge: Verify evidence and compute conservative verdict
    end
    Flow-->>Route: Structured result and evidence
    Route->>Store: Save result under the user's session
    Route-->>Client: Match response with session ID
    Client-->>UI: Display results and clinical assessment
```
